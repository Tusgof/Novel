Date: 2026-10-03
Scope: replace production dispatch with Lean and separate project/novel ownership.

## Delivered

- Canonical runtime: root `novel_pipeline/`, installed with `python -m pip install -e .`.
- All five registered configs select Lean; new-novel scaffolding also selects Lean.
- Shared prompts: root `prompts/lean/`; novel refinement voice: `<Novel>/.system/lean_voice.md`.
- Provider helpers resolve within the selected vault or root shared scripts only; sibling paths and mismatched provider cwd are rejected.

- Production checkpoint/trace paths remain within selected-vault `_lean_runs`; experiment paths remain within selected-vault work state, outside product output. Run IDs cannot traverse directories, and resume must preserve novel/run/chapter scope.
- Root CLI rejects legacy engines and legacy stage operations for Lean configs. Historical modules/import shims remain for regression and artifact recovery, not new production dispatch.
- Removed the 36 duplicate DSE-local runtime modules after validating their root counterparts; the DSE package retains only its import shim. Runtime history remains in git.
- Literal translation and term harvest now honor existing configured fallback routes. No model routing was changed.
- A disk failure after an earlier chapter was promoted stops the run and records exactly which files reached product output; it cannot falsely report zero promotion.
- Architecture, brain, plan, operator guide and Chinese language playbook now describe the Lean flow rather than mandatory scan/OOS/AI-formatting steps.
