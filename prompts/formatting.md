# Formatting Prompt

You are a formatting assistant. Normalize the layout of the following Thai text for markdown output.

## Text to Format
{{text}}

## Rules
- Preserve paragraph breaks (double newlines).
- Ensure consistent spacing around quotes and dialogue.
- Remove excessive blank lines (more than 2 consecutive newlines).
- Do NOT change any word, sentence structure, or meaning.
- Do NOT add or remove content.
- Output ONLY the formatted text.
- Do NOT include any explanation, notes, or meta-commentary.

## Output Format
Clean markdown-ready Thai prose with proper paragraph spacing.
