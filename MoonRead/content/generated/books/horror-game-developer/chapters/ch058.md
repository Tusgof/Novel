# ตอนที่ 58 - การกลับมาของตัวตลก [1]

เอาละ ทุกคนสนใจทางนี้หน่อย! เสียงตะโกนดังลั่นปลุกโซอี้ให้ตื่นจากภวังค์ เธอวางโทรศัพท์ลงบนโต๊ะแล้วนั่งตัวตรง สายตาจับจ้องไปข้างหน้าเมื่อหัวหน้าแผนกปรากฏตัวในสภาพที่ดูไม่ได้และงัวเงีย เขาเกาคางที่ไม่ได้โกนอย่างเหม่อลอย มือถือเอกสารหลายฉบับที่กำลังโบกไปมา ผมเพิ่งได้รับรายงานเรื่องเกต ผมมั่นใจว่าพวกคุณส่วนใหญ่คงรู้แล้วว่าผมหมายถึงเกตไหน มันเป็นเกตแบบจัดอันดับ เพราะงั้นมันไม่ได้ใหญ่อะไรมาก ผมต้องการใครก็ได้ที่เป็นระดับสามหรือสี่มานำทีม

จากนั้นหัวหน้าแผนกก็กวาดสายตาดูเอกสาร เขาเดาะลิ้นพลางพึมพำว่า ไคล์... เขาไม่อยู่ที่นี่ เพราะงั้นผมคงโยนเรื่องน่ารำคาญนี่ให้เขาไม่ได้ ถ้าอย่างนั้นละก็... หัวหน้าแผนกเงยหน้าขึ้นและในที่สุดก็สบตากับโซอี้ที่รู้สึกใจหายวูบ เธอพอเดาออกแล้วว่าเรื่องนี้จะจบลงยังไง

โซอี้! เขายิ้ม มันเป็นรอยยิ้มที่น่ารังเกียจซึ่งโซอี้เห็นมานับครั้งไม่ถ้วนจนถึงตอนนี้ มันน่าขยะแขยงสิ้นดี

ไม่ค่ะ

คุณยังไม่รู้เลยว่าผมจะขออะไร

...จริงๆ ฉันรู้ค่ะ คุณแสดงออกชัดเจนขนาดนั้นแล้ว ฉันไม่มีเวลาไปดูแลปฏิบัติการหรอกค่ะ ฉันกำลังพยายามรวบรวมเศษเสี้ยวให้มากพอเพื่อเลื่อนระดับถัดไปอยู่

คุณขาดอะไรบ้างล่ะ?

...ฉันขาดเศษเสี้ยวแห่งแสงสิบชิ้น แก่นแท้แห่งแสงหนึ่งชิ้น และหัวใจของสิ่งผิดปกติธาตุแสงระดับห้าอีกหนึ่งดวงค่ะ

สรุปสั้นๆ คือเธอยังขาดของอีกเยอะมาก แต่ก็ช่วยไม่ได้ ยิ่งระดับสูงขึ้นเท่าไหร่ การเลื่อนระดับก็ยิ่งยากขึ้นเท่านั้น ขึ้นอยู่กับบัญญัติที่เลือกไว้ แต่ละคนต้องทำตามรายการไอเทมและเศษเสี้ยวที่กำหนดเพื่อกระตุ้นโหนดถัดไป และต่อให้เธอหาไอเทมที่จำเป็นครบทั้งหมด ก็ไม่มีอะไรรับประกันว่าเธอจะปลดล็อกโหนดถัดไปได้สำเร็จ เธอไม่มีเวลาไปลงทุนกับเกตแบบจัดอันดับจริงๆ

อูย แม้แต่หัวหน้าแผนกยังดูเห็นใจเธออยู่บ้าง จำนวนไอเทมนั้นไม่น้อยเลย ถึงอย่างนั้น มันก็ใช่ว่าเขาจะไม่มีทางออกสำหรับเรื่องนี้

ผมจะให้คุณหนึ่งหมื่นแต้ม คุณจะรับงานนี้ไหม?

ขอเป็นหนึ่งหมื่นสองพันแต้มแล้วฉันจะตกลงค่ะ

.....

ว่าไงคะ?

....ก็ได้ หัวหน้าแผนกเดาะลิ้นในขณะที่โซอี้แสยะยิ้ม นี่คือสิ่งที่เธอเล็งไว้ตั้งแต่แรก กิลด์มีระบบความดีความชอบเฉพาะตัวที่มาในรูปแบบของแต้ม หากมีแต้มมากพอ เธอจะสามารถซื้อไอเทมที่จำเป็นสำหรับการเลื่อนระดับได้ และบังเอิญว่าหนึ่งหมื่นสองพันแต้มนั้นเพียงพอที่จะซื้อหนึ่งในไอเทมที่เธอต้องการพอดี มันอาจจะยังต้องใช้เวลาอีกพักใหญ่กว่าจะเลื่อนระดับได้ แต่อย่างน้อยเธอก็เข้าใกล้ไปอีกก้าวหนึ่ง

ตรวจสอบให้แน่ใจว่าคุณจะไม่ทำภารกิจล้มเหลว คุณไม่ใช่คนเดียวที่จะเข้าไปข้างใน คุณต้องระวังพวกเวรจากไอวอรี่และคราวน์ฟอลให้ดี คุณก็รู้ว่าเกิดอะไรขึ้นครั้งล่าสุดที่เราอยู่กับพวกนั้น

รับทราบค่ะ โซอี้เอื้อมมือไปหยิบแฟ้มจากมือของหัวหน้าแผนก ในนั้นเธอเห็นรายงานรายละเอียดทั้งหมดจากหน่วยสอดแนม

———

คิ้วของเธอขมวดเข้าหากันทันทีเมื่ออ่านส่วนแรกของรายงานขณะที่นั่งตัวตรงบนเก้าอี้ เป็นไปตามคาด สถานการณ์นี้ดูไม่ใช่งานง่ายเลย

ยุ่งยากชะมัด...

สุดท้าย ผมก็ไม่ได้ซื้ออะไรเลย ผมแค่ใช้เวลาส่วนใหญ่ไปกับการไล่ดูไอเทมและจดจำคำอธิบายของพวกมัน มีไอเทมดีๆ เยอะเกินไปจนผมตัดสินใจไม่ถูก แต่ที่สำคัญกว่านั้น...

[ที่ปรึกษาด้านบาดแผลทางจิตใจ]

ผมมองดูป้ายโลหะแวววาวที่วางอยู่บนโต๊ะด้วยความรู้สึกที่ปนเปกัน นี่เป็นเพียงป้ายตามธรรมเนียมที่กิลด์มอบให้เพื่อให้งานของผมดูเป็นทางการ แต่ผมกังวลว่าคนอื่นจะจริงจังกับมันหรือเปล่า แล้วถ้าเป็นงั้นล่ะ...?

ตัวผมเองก็มีบาดแผลทางจิตใจอยู่เต็มไปหมด ถ้าจะว่ากันตามตรง ผมนี่แหละคือคนที่ต้องการคำปรึกษา

เอาเถอะ ถ้ามันถึงที่สุดจริงๆ ผมก็แค่บอกความจริงไป ยังไงซะพวกเขาก็ควรจะรู้ไว้... ว่าผมไม่มีคุณสมบัติพอจะเป็นที่ปรึกษาอะไรนั่นหรอก

แต่อีกแง่หนึ่ง นี่อาจเป็นโอกาสดีที่ผมจะได้สร้างเส้นสายบ้าง

อา ช่างมันเถอะ ผมปัดความคิดเหล่านั้นทิ้งไปและหันความสนใจกลับไปยังภาพวาดตรงหน้า ผมลุกขึ้นจากที่นั่งและพิจารณามันอย่างถี่ถ้วน เด็กสาวในภาพยังอยู่ในตำแหน่งเดิมเหมือนตอนที่ผมได้รับมา และดูเหมือนจะไม่มีอะไรผิดปกติอีกแล้ว ผมจึงถอนหายใจด้วยความโล่งอก

...ในเมื่อผมไม่ต้องมองมันตอนกลางคืนแล้ว มันก็ควรจะเป็นแค่ภาพวาดธรรมดา

ผมคิดจะแขวนภาพนั้นไว้บนผนังต่อ แต่แล้วก็นึกถึงเรื่องสำคัญอย่างหนึ่งขึ้นมาได้ ภาพวาดนี้... จริงๆ แล้วมันถูกขโมยมา

อา ซวยแล้ว ผมครางออกมาเบาๆ เมื่อนึกขึ้นได้ แม้ผมจะมั่นใจว่าคงไม่มีใครจำภาพวาดนี้ได้มากนัก แต่ในเมื่อมีเกตเกิดขึ้นในพื้นที่ที่พิพิธภัณฑ์ตั้งอยู่ ผมแน่ใจว่าต้องมีบางคนไปสืบค้นข้อมูลเกี่ยวกับสถานที่นั้นมาบ้าง พวกนั้นต้องจำมันได้ในทันทีแน่นอน

แต่มันมีบางอย่างที่สำคัญกว่านั้น ผมนึกย้อนกลับไปถึงสถานการณ์จำลองและเรื่องที่พิพิธภัณฑ์ถูกทิ้งร้างเพราะภาพวาดถูกขโมยไป

ความคิดนั้นทำให้ผมรู้สึกไม่สบายใจขณะที่จ้องมองภาพวาดอย่างตั้งใจ

ตอนนี้ เอาลงมาก่อนน่าจะดีที่สุด

ขณะที่ผมเอื้อมมือไปจับขอบภาพเพื่อจะยกมันลง นิ้วของผมสัมผัสกับกรอบเก่าๆ ที่พยุงภาพวาดไว้ แต่แล้วบางอย่างก็สะดุดตาผมพอดีจนทำให้ผมต้องชะงัก

.....?

ผมค่อยๆ หันกลับไปมองที่ภาพวาด ความรู้สึกหนักอึ้งเริ่มก่อตัวขึ้นในอก และแล้ว—

ผมก็เห็นมัน

.....!?

ใบหน้าของเด็กสาวตัวน้อย ใบหน้าของเธอซีดเผือดและดวงตาเบิกกว้าง จ้องมองมาที่ผมในระยะประชิด

สมองของผมว่างเปล่าไปชั่วขณะ ผมยังไม่ทันได้กรีดร้องด้วยซ้ำก่อนที่มือน้อยของเธอจะพุ่งออกมาด้วยความเร็วที่ผิดธรรมชาติ คว้าหัวของผมแล้วกระชากผมเข้าไปข้างหน้า
