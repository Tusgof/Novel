# ตอนที่ 67 - เสียงร้องไห้ [3]

“เราควรทำยังไงดี? จะไปกันเลยไหม?”

“...ไม่ ยังก่อน”

ทอมหยุดทีมของเขาไว้ตรงหน้าพอร์ทัล หันกลับไปมองคฤหาสน์ ดวงตาหรี่ลงภายใต้หน้ากาก เขาเห็นพวกคราวน์ฟอลล์ยังคงปักหลักอยู่แถวประตู ดูเหมือนพวกนั้นจะคิดแบบเดียวกับเขา

*‘เควสต์ลับ...’*

ใช่แล้ว แม้สถานการณ์หลักจะเสร็จสมบูรณ์ แต่ก็ยังมีสถานการณ์ลับที่ทำสำเร็จได้ โดยทั่วไปแล้วสถานการณ์ลับนั้นหายาก และมักมาพร้อมรางวัลมหาศาล เมื่อรู้แบบนี้แล้วจะกลับไปได้ยังไง? เสียดายจะตาย!

“หัวหน้าหน่วย พวกกิลด์ดวงดาวที่ถูกตัดขาดกำลังไปแล้วครับ”

“หืม?”

ทอมละสายตาจากอาคารหลัก หันไปมองสมาชิกกิลด์ดวงดาวที่ถูกตัดขาดที่ค่อยๆ เคลื่อนตัวเข้าสู่พอร์ทัลและหายไป คิ้วของเขาเลิกขึ้นครู่หนึ่ง พวกนั้นไปแล้วเหรอ...? ไปง่ายๆ แบบนั้นเลย? ไม่ลองเสี่ยงกับสถานการณ์ลับหน่อยเหรอ?

“หึ”

เสียงหัวเราะเบาๆ หลุดจากปากทอมขณะมองดูคนเหล่านั้น สมกับเป็นพวกนั้นจริงๆ... นี่คือความแตกต่างระหว่างกิลด์ของพวกเขา นี่คือช่องว่างระหว่างกิลด์ระดับราชาและกิลด์ระดับราชินี พวกเขาพร้อมรับความเสี่ยง ไม่ขี้ขลาดเมื่อโอกาสมาอยู่ตรงหน้า

แต่ราวกับว่าความคิดของเขาเพียงอย่างเดียวยังพิสูจน์ไม่พอ สิ่งที่เขาเพิ่งเห็นคือหลักฐานทั้งหมดที่เขาต้องการ เขาส่ายหน้า หันไปมองสมาชิกในทีม

“ไม่ต้องไปสนใจพวกนั้นมากหรอก ดีสำหรับเราแล้วที่พวกนั้นไป นั่นหมายความว่าเราจะได้รางวัลมากขึ้นเมื่อเคลียร์สถานการณ์ได้”

ทอมก้าวออกจากกลุ่ม หยิบอุปกรณ์เฉพาะอย่างหนึ่งที่ใช้ภายในเกตได้ มันเป็นอุปกรณ์ที่ค่อนข้างแพง การโทรแต่ละครั้งต้องเสียเงินจำนวนมหาศาล อย่างไรก็ตาม เมื่อพิจารณาสถานการณ์ปัจจุบัน เขารู้สึกว่าจำเป็นต้องโทรออก เขาต้องถามกิลด์เกี่ยวกับสถานการณ์นี้ก่อนดำเนินการต่อ และนั่นคือสิ่งที่เขาทำ

โลกทั้งใบมืดมิด ...อย่างน้อยก็ในตอนแรก แต่แล้วแว่นตาก็ทำงาน ภาพตรงหน้าก็คมชัดขึ้น ทางเดินยาวเหยียดทอดตัวอยู่เบื้องหน้า พรมสีแดงเข้มปูลาดใต้เท้าผม นำทางไปสู่ประตูที่เปิดแง้มไว้เล็กน้อย แสงสีส้มอบอุ่นลอดออกมาจากข้างใน

แสงเหรอ?

ผมรู้สึกว่าร่างกายเกร็งขึ้นเล็กน้อยเมื่อเห็นภาพนั้น

*‘ผมตาฝาดไปเอง หรือว่า...?’*

ผมค่อยๆ ถอดแว่นออกเพื่อความแน่ใจ และแน่นอนว่าแสงยังคงลอดออกมาจากประตูที่เปิดแง้มอยู่ไกลๆ นั่น ผมเลียริมฝีปาก จ้องไปในทิศทางนั้น

แต่แล้ว—

จู่ๆ ผมก็ได้ยินเสียงดังมาจากหลังประตู มันฟังดูเหมือนเสียงพูดคุยเบาๆ ปนกับเสียงกระทบกันของโลหะบางๆ อธิบายยาก แต่ผมรู้สึกไม่ค่อยดีกับสถานการณ์นี้เลย ถึงอย่างนั้น ผมก็ยังตัดสินใจเคลื่อนที่เข้าไปดูใกล้ๆ

ทุกย่างก้าวที่ผมเดิน หัวใจเต้นระรัวอยู่ในอก ผมต้องเตือนตัวเองซ้ำแล้วซ้ำเล่าให้สงบสติอารมณ์ ผมจะปล่อยให้ความกลัวเข้าครอบงำจิตใจไม่ได้ แม้ใจจริงอยากวิ่งหนีไปให้พ้น

เอ่อ... บางที บางทีนะ ผมอาจจะทำให้เรื่องมันแย่ลงสำหรับตัวเอง ไม่สิ ผมทำจริงๆ นั่นแหละ...

ผมกลืนความรู้สึกคลื่นไส้ที่ตีตื้นขึ้นมาจากท้องลงไป แล้วก้าวเข้าไปใกล้ประตู ยื่นหน้าเข้าไปมองผ่านช่องแคบๆ นั่นคือตอนที่ผมได้เห็นมัน

ห้องอาหารขนาดใหญ่ มีโต๊ะยาวตั้งอยู่ตรงกลาง คลุมด้วยผ้าปูโต๊ะสีขาวสะอาดตา ขาวเกินไป เหมือนกระดูกที่ถูกฟอกขาว เทียนไขวูบไหวอยู่ตามความยาวของโต๊ะ ทอดเงายาวที่สั่นระริกทับจานที่จัดวางอย่างเป็นระเบียบและดอกไม้ที่เหี่ยวเฉา โคมไฟระย้าแขวนอยู่ด้านบน คริสตัลของมันสะท้อนเปลวไฟที่วูบไหวของเทียนด้านล่าง ภาพวาดที่มีใบหน้าพร่ามัว เลอะเทอะ หรือหันหลังให้ ถูกแขวนไว้อย่างบิดเบี้ยวบนผนัง ขณะที่ปลายทั้งสองด้านของห้องมีประตูไม้ขนาดใหญ่ปิดสนิท

แต่สิ่งที่ทำให้ผมตัวแข็งทื่อ... สิ่งที่ฝังเข็มเย็นเยียบลงในกระดูกสันหลังของผม... คือร่างสี่ร่างที่นั่งอยู่ที่โต๊ะ

พวกเขานั่งตัวตรง กินอาหารและพูดคุยกันด้วยเสียงอู้อี้ ส้อมเคาะกับจาน เกิดเสียงแกร๊กๆ ที่คุ้นเคยก่อนหน้านี้ คนรับใช้ร่อนไปมาระหว่างพวกเขา เข้าออกประตูบานหนึ่งโดยไร้เสียง และทุกคน... ไม่มีใบหน้า

มีเพียงผิวหนังว่างเปล่าในจุดที่ควรจะเป็นอวัยวะบนใบหน้า ราวกับว่าพวกมันถูกลบออกไป ถึงอย่างนั้นพวกเขาก็ยังเคี้ยว ยังคงพูดคุย... ได้ยังไงไม่รู้

ผมต้องสูดลมหายใจเข้าลึกๆ และเย็นเยียบเมื่อเห็นภาพนั้น นี่มันอะไรกัน... ผมไม่อาจละสายตาจากภาพตรงหน้าได้ ไม่ใช่เพราะผมกลัว แต่เพราะผมจำพวกเขาได้

ใช่แล้ว พวกเขาคือคนสี่คนเดียวกับในภาพวาดข้างล่าง เพียงแต่พวกเขาไม่มีใบหน้า เหตุผลเดียวที่ผมบอกได้คือเสื้อผ้าของพวกเขา มันเหมือนกับในภาพวาดเป๊ะๆ พวกเขาอาจจะเป็นเจ้าของคฤหาสน์หลังนี้หรือเปล่า? ถ้าเป็นอย่างนั้น...

“.....!”

เสียงคลิกแห้งๆ ที่แปลกประหลาดทำลายความเงียบ ตามมาด้วยเสียงส้อมหล่นกระทบพื้น หัวของพวกเขาทุกคนหันขวับไปยังต้นเสียง ดวงตาที่ว่างเปล่าจ้องจับไปที่อุปกรณ์ที่ตกลงมาขณะที่มันไถลไปตามพื้นจนกระทั่ง... มันหยุดลงในทิศทางเดียวกับประตูที่ผมยืนอยู่ข้างหลัง

“.....!”

หัวใจผมแทบหยุดเต้น

...และผมก็รีบผละออกมาทันที ถอยห่างจากประตูพลางกุมหัวใจที่เต้นรัว ความเงียบที่แปลกประหลาดตามมาในไม่ช้า ความเงียบที่รู้สึกอึดอัดอย่างที่สุดขณะที่ผมถอยหลังไปหลายก้าว

และแล้ว—

เสียงฝีเท้าที่แผ่วเบาที่สุดดังขึ้นในความเงียบ มันอยู่ไกล แต่...

มันกำลังเคลื่อนที่มาทางประตูอย่างช้าๆ

เหงื่อไหลซึมลงข้างแก้มขณะที่ผมถอยหลังต่อไป

แต่ละก้าวลากยาว เข้าใกล้ประตูมากขึ้นเรื่อยๆ ผมไม่กล้าแม้แต่จะหายใจ ผมหายใจไม่ออก ผมถอยมาจนสุดทางเดิน เอื้อมมือไปหาประตูที่ผมเข้ามา แต่...

มันล็อคอยู่

ผมรู้สึกถึงความกดดันที่เพิ่มขึ้นจนแทบหายใจไม่ออก เมื่อประตูที่ปลายสุดของทางเดินส่งเสียงเอี๊ยดอ๊าดเปิดออก บานพับของมันครางประท้วงในทุกๆ นิ้วที่ขยับ

สายตาของผมกวาดไปที่ร้านค้าตรงหน้า เตรียมที่จะซื้อไอเทมบางอย่าง ทันใดนั้น—

เสียงร้องไห้พลันดังระงมไปทั่วพื้นที่ ประตูหยุดเคลื่อนไหว สิ่งที่ตามมาคือเสียงที่สั่นเครือและอ่อนแรง

“หิวจังเลย ผม... ห-หิวจริงๆ นะ”
