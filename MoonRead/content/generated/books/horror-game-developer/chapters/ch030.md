# ตอนที่ 30 - เควสต์สำเร็จ [1]

**[พัฒนาเกมที่มีคะแนน 1 ดาว]**
**[ภารกิจเสร็จสิ้น]**

การแจ้งเตือนหลายสายพุ่งผ่านสายตาของผมไปอย่างกะทันหัน ผมได้แต่จ้องมองพวกมันด้วยความสับสน

“อะไรกันวะเนี่ย...?”

ผมทำภารกิจสำเร็จงั้นเหรอ? ...แต่ทำไมต้องเป็นตอนนี้ด้วยล่ะ? ผมทำเกมเสร็จไปตั้งชั่วโมงหนึ่งแล้ว ทำไมถึงเพิ่งมาเด้งเอาตอนนี้?

การแจ้งเตือนยังไม่จบลงเพียงเท่านั้น

**[กำลังคำนวณรางวัล...]**

จิตใจของผมตื่นตัวขึ้นมาทันทีเมื่อเห็นการแจ้งเตือนล่าสุด แม้จะยังงุนงงว่าเรื่องทั้งหมดนี้เกิดขึ้นได้อย่างไร แต่ผมก็อดไม่ได้ที่จะรู้สึกตื่นเต้นกับส่วนของรางวัล—โดยเฉพาะส่วนของ 'ร้านค้า' ผมมีความรู้สึกว่าสิ่งที่ผมต้องการกำลังรอผมอยู่ที่นั่น

**[คำนวณรางวัลเสร็จสิ้น]**

ติ๊ง—!

เสียงกังวานใสๆ ดังขึ้นในหัว พร้อมกับหน้าต่างบานใหม่ที่ปรากฏขึ้นตรงหน้า

**[+ 1,000 SP]**
**[ปลดล็อกร้านค้า!]**

─────**[ร้านค้า]**─────
-> **[คำสั่งซื้อครั้งแรก]**

**[มีดปังตอ]** : มีดที่มีความสามารถในการตัดผ่านวัตถุและตัวตนที่ผิดปกติ ยิ่งฆ่ามากเท่าไหร่ มันก็ยิ่งแข็งแกร่งขึ้นเท่านั้น! ไม่ใช่ไอเทมใช้แล้วทิ้ง
ราคา : 10,000 SP

**[คุณฮักส์]** : ตุ๊กตาหมีสกปรกที่ช่วยลดความก้าวร้าวในรัศมี 5 เมตร อย่างไรก็ตาม การสัมผัสเป็นเวลานานจะทำให้เกิดการเสพติดอย่างรุนแรงและความไม่มั่นคงทางอารมณ์เมื่อต้องแยกจากกัน
ราคา : 2,178 SP

**[ช่องสัญญาณมรณะ]** : วิทยุที่จูนได้เฉพาะสถานีที่กระจายเสียงของคนตาย บางครั้งพวกเขาก็จะตอบคำถามด้วย
ราคา : 999 SP

**[แต้มที่มี : 1,000 SP]**
**[อัตราการแลกเปลี่ยน : 1$ = 0.1 SP]**
─────**[ร้านค้า]**─────

ผมตกใจกับอินเทอร์เฟซที่ทักทายผมทันที มีไอเทมมากมาย แต่ละชิ้นมีคำอธิบายและราคาติดไว้

“10,000 SP?” นี่คือสกุลเงินที่ใช้ในร้านค้าสินะ?

ผมได้รับคำตอบในไม่ช้าเมื่อเหลือบไปเห็นข้อมูลที่เกี่ยวข้อง

“อัตราการแลกเปลี่ยน? 1 ดอลลาร์ต่อ 0.1 SP? แบบนี้มัน...”

นี่มันปล้นกันชัดๆ ไม่ใช่เหรอ? ถ้าคำนวณจากเงินเก็บทั้งหมดของผมที่มีอยู่ประมาณ 7,000 ดอลลาร์ มันก็แลกได้แค่ 700 SP เท่านั้นเอง แล้วผมจะไปซื้ออะไรได้?

“ไม่สิ จริงๆ มันก็มีของอยู่ไม่น้อยนะ...”

ทางด้านขวาของหน้าต่าง มีแถบค้นหากะพริบอยู่เบาๆ — ข้างๆ กันมีตัวเลขแสดงจำนวนไอเทมทั้งหมดที่มี

**[ค้นหา █──────────]**
ไอเทมทั้งหมด: 137

เมื่อเห็นตัวเลข ผมก็รู้สึกประหลาดใจในทางที่ดี มันเยอะพอสมควรเลย ผมยังเห็นอีกว่ามีไอเทมมากกว่าที่แสดงอยู่ แต่ส่วนเหล่านั้นยังถูกล็อกไว้ ไอเทมเดียวที่ผมเข้าถึงได้คือไอเทมในส่วน **[คำสั่งซื้อครั้งแรก]**

‘...ผมก็อยากรู้เหมือนกันว่ามันหมายความว่ายังไง แต่ตอนนี้เรื่องนั้นยังไม่สำคัญ’

มีเพียงสิ่งเดียวที่อยู่ในหัวของผมตอนนี้ นั่นคือ...

“ยา ผมต้องหายา”

ผมบอกได้เลยว่าอาการของผมเริ่มแย่ลง โดยเฉพาะเมื่อมีความเครียดสะสมและการอดนอนเข้ามาซ้ำเติม ผมยังมียาของตัวเองอยู่ แต่นั่นมันก็แค่ยาระงับอาการเฉยๆ พวกมันไม่ได้รักษาอาการจริงๆ แถมยังเริ่มจะดื้อยาขึ้นเรื่อยๆ แล้วด้วย

“มันอยู่ไหนนะ...?”

เมื่อกดที่แถบค้นหา ตัวกรองก็ขยายออกมาด้านล่าง แบ่งไอเทมเป็น 'ไอเทมใช้สิ้นเปลือง' และ 'ไอเทมไม่ใช้สิ้นเปลือง' แถบเลื่อนราคากะพริบขึ้นมาหลังจากนั้น และผมก็จำกัดราคาไว้ที่ 1,700 SP ซึ่งเป็นยอดรวมรายได้ทั้งหมดของผมในตอนนี้

ยอดคงเหลือทำให้ผมแปลกใจ มันสูงกว่าที่คาดไว้ แต่นั่นไม่สำคัญ การหายาให้เจอคือสิ่งเดียวที่สำคัญ

ไอเทมที่พร้อมใช้งาน : 12

ผมรีบเลื่อนดูไอเทมต่างๆ จนกระทั่งสายตาไปหยุดอยู่ที่ไอเทมชิ้นหนึ่ง

(แนะนำ)
**[ลูเมนอล]** : ยับยั้งการแพร่กระจายของ 'รอยแยก' (Fractures) เป็นเวลาหนึ่งสัปดาห์ ช่วยบรรเทาอาการทันทีและป้องกันการเติบโตของ 'เศษเสี้ยวการรับรู้' (Cognate Shard) ใหม่
ไอเทมใช้สิ้นเปลือง
ราคา : 250 SP

“เอ๊ะ?”

พออ่านคำอธิบาย ผมก็ไปไม่เป็นเลย รอยแยก? เศษเสี้ยวการรับรู้? สองคำนี้มันหมายความว่ายังไงกันแน่? ผมไม่เข้าใจสักนิด คำอธิบายมันน่าสับสน แต่ผมก็ไม่มีอะไรที่จะช่วยให้เข้าใจความหมายของพวกมันได้เลย

‘เดี๋ยวค่อยลองถามไคล์ดูแล้วกัน เขาอาจจะรู้อะไรบ้าง’

ผมรู้สึกว่าคำพวกนี้มีความเกี่ยวข้องอย่างใกล้ชิดกับระบบของโลกใบนี้ นอกเหนือจากนั้น...

เมื่อมองไปที่ป้ายราคา ผมก็สูดหายใจเข้าลึกๆ ด้วยความหนาวเหน็บ

“250 SP? แพงชะมัด”

บอกตามตรง ผมคงเลื่อนผ่านมันไปแล้วถ้าไม่มีคำว่า 'แนะนำ' เล็กๆ นั่นติดอยู่ข้างชื่อไอเทม ผมเข้าใจได้ในทันทีว่านี่คือคำใบ้ที่ระบบมอบให้เกี่ยวกับอาการของผม ถึงจะยังสงสัย แต่ผมก็ตัดสินใจซื้อไอเทมชิ้นนั้น โดยคลิกที่ปุ่ม 'ซื้อ' ที่อยู่ด้านล่าง

ทันทีที่ผมกดปุ่ม ยอดคงเหลือของผมก็ลดลงเหลือ 750 และมีการแจ้งเตือนกะพริบขึ้นมา

**[การซื้อเสร็จสิ้น!]**

ปุ้ง!

เสียงดังปุ้งที่คุ้นเคยดังขึ้น และมีไอเทมตกลงมาจากด้านบน

“อุ๊ย!”

ไอเทมตกลงมาใส่ข้อมือผมพอดีขณะที่ผมรับมันไว้

“...นี่คือยางั้นเหรอ?”

มันเป็นเม็ดสีขาวขนาดประมาณยาทั่วไป อันที่จริง ทั้งรูปลักษณ์และสัมผัสของมันเหมือนยาปกติไม่มีผิด ผมถือมันไว้ระหว่างนิ้ว แอบคาดหวังว่ามันจะส่งเสียงหึ่งๆ หรือขยับได้ หรือทำอะไรแปลกๆ บ้าง แต่มันก็ไม่ทำอะไรเลย มันแค่หยิ่งนิ่งอยู่อย่างนั้น ดูธรรมดาๆ

‘ควรจะกินน้ำตามไหมนะ?’

ไม่มีคำแนะนำบอกไว้ แต่เมื่อดูจากลักษณะของมันแล้ว ผมก็ไปหยิบน้ำมาแก้วหนึ่งก่อนจะกลืนยาลงไป

ยาไหลลงสู่กระเพาะอย่างราบรื่นหลังจากนั้น และผมก็นั่งลง รอให้บางอย่างเกิดขึ้น

‘เดี๋ยวก็คงรู้’

ผมรอ รอให้บางอย่างเกิดขึ้น ผมรอแล้วรอเล่า แต่ทว่า...

“....”

ผมลืมตาขึ้นแล้วขมวดคิ้ว ผมไม่รู้สึกอะไรเลยสักนิด

‘มีอะไรผิดพลาดหรือเปล่า? หรือว่าผมกินไม่ถูกวิธี?’

ผมเปิดร้านค้าขึ้นมาอีกครั้งและอ่านคำอธิบาย ทว่าดูเหมือนจะไม่มีคำแนะนำในการใช้ระบุไว้เลย

“หรือว่าผลของมันจะไม่ชัดเจน...?”

ผมก้มหน้าลงเช็กเวลาและวันที่

“...ปกติผมจะมีอาการกำเริบทุกๆ สิบสองชั่วโมง ผมจะเริ่มจับเวลาตอนนี้เลยแล้วกันเพื่อดูว่ามันได้ผลไหม”

นี่เป็นวิธีเดียวที่ผมจะตรวจสอบได้ว่ายาได้ผลหรือไม่ หลังจากเริ่มจับเวลาได้ไม่นาน สายตาของผมก็เหลือบไปเห็นร้านค้าอีกครั้ง มือของผมเริ่มคันยิบๆ ขณะจ้องมองไอเทมมากมาย โดยเฉพาะ **[มีดปังตอ]** บนหน้าแรกนั่น

‘ถ้าผมมีเจ้านั่น การสู้กับพนักงานตรวจตั๋วคงจะง่ายขึ้นใช่ไหม?’

ผมอยากได้มันจริงๆ แต่ผมไม่มีเงินพอที่จะซื้อ ไม่ใช่แค่ไอเทมชิ้นนั้นที่ผมสนใจ มีไอเทมที่มีประโยชน์อีกมากมายที่ผมอยากได้ใจจะขาด แต่ก็นั่นแหละ ปัญหาของผมคือการขาดแคลนเงิน

ผมต้องหาเงินให้ได้ไม่ทางใดก็ทางหนึ่ง แต่มันก็ไม่ใช่เรื่องง่ายเลย ผมไม่มีงานทำ และสิ่งเดียวที่ผมมีตอนนี้ก็คือ—

“เดี๋ยวก่อน!”

ความคิดหนึ่งแล่นเข้ามาในหัวทันที ผมรีบดึงคอมพิวเตอร์ออกมาเปิดแอป แล้วสายตาก็ไปหยุดอยู่ที่คะแนนของเกม

“หนึ่งดาว...”

ผมเอามือปิดปาก

‘ใช่แล้ว ผมไม่ได้สร้างเกมขึ้นมาเพื่อทำภารกิจให้สำเร็จอย่างเดียว ผมยังสามารถขายมันและหวังว่ามันจะทำเงินได้ด้วย’

ปัญหาเดียวที่มีคือมันจะทำเงินได้ไหม เมื่อพิจารณาว่าระบบให้คะแนนไว้หนึ่งดาว มันก็คงไม่แย่เกินไปใช่ไหม?

“สมมติว่าเกมมันดี แต่ผมก็ยังถูกมองว่าเป็นแค่นักพัฒนาอินดี้ กลุ่มเป้าหมายที่ผมเข้าถึงได้มันไม่กว้างนัก ผมต้องหาวิธีการตลาดและแรงผลักดันที่เหมาะสมเพื่อให้มันขายได้”

ผมบีบขมับขณะเค้นสมองคิดหาวิธี และในระหว่างที่กำลังคิดอยู่นั้น การแจ้งเตือนก็กะพริบขึ้นมา

ติ๊ง!

ผมเงยหน้าขึ้นช้าๆ เพื่อดูสิ่งที่ปรากฏตรงหน้า

**[มอบหมายภารกิจใหม่!]**
**[คุณได้สร้างเกมที่เหมาะสมในการทำให้ผู้คนในโลกนี้หวาดกลัว มันคงน่าเสียดายถ้าโลกไม่รู้จักเกมของคุณ จงหาวิธีการตลาดให้เกมของคุณและทำยอดขายให้ได้อย่างน้อย 10,000 ชุด!]**

**[รางวัล : 3,000 SP]**
**[บทลงโทษหากล้มเหลว : ปิดร้านค้า]**
**[เวลาจำกัด : หนึ่งสัปดาห์]**

ผมอ้าปากค้างก่อนจะหุบลง จากนั้น...

“เอาเถอะ”

ผมพยักหน้าก่อนจะทิ้งตัวลงบนเตียงและเอาผ้าห่มคลุมโปง

“...ช่างแม่งเหอะ”
