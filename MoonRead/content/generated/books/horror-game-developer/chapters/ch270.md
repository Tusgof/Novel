# ตอนที่ 270 - ความสิ้นหวังในความสมบูรณ์แบบ [5]

*ตึง ตัง—*

ร่างกายของผมขยับไปเอง ความรู้สึกมันต่างจากครั้งก่อนๆ ผมไม่สามารถควบคุมร่างกายตัวเองได้อีกต่อไป ผมมองเห็น ได้ยิน และมีสติครบถ้วน แต่เมื่อถึงคราวที่ต้องเคลื่อนไหวจริงๆ...

*ตึง—!*

ผมไม่ใช่คนขยับมันเอง

*ตึง! ตึง— ตึง—!*

ตัวโน้ตนั้นเฉียบคมและดังกังวานท่ามกลางความเงียบงัน ความมืดมิดที่แผ่ขยายไปทุกทิศทางกดทับลงมาหนักหน่วงยิ่งขึ้นในขณะที่ผมบรรเลงเพลง และในวินาทีนั้น จู่ๆ ผมก็รู้สึกเหมือนมีดวงตาคู่หนึ่งจับจ้องมาที่ผมอย่างแน่นหนา ผมสัมผัสได้ถึงความหวาดกลัวที่คืบคลานเข้ามา มันเติบโตขึ้นตามทุกตัวโน้ตที่ผมเล่น แต่ถึงอย่างนั้น— ผมก็ยังคงเล่นต่อไป ผมหยุดไม่ได้

ตึง, ตึง— การเคลื่อนไหวของผมช่างลื่นไหล มันดูง่ายดาย และที่สำคัญที่สุดคือผมไม่เล่นพลาดเลยแม้แต่นิดเดียว ผมจำแผ่นเพลงที่ต้องเล่นได้ขึ้นใจนานแล้ว ต่อให้ไม่มีการสะกดจิต ผมก็เล่นเพลงนี้ได้ แต่ตอนนี้มันต่างออกไป ระดับเสียงสมบูรณ์แบบ จังหวะสมบูรณ์แบบ ท่วงท่าและท่วงทำนองก็สมบูรณ์แบบเช่นกัน ไม่มีข้อบกพร่องใดๆ ในบทเพลงของผมเลย ทำนองนั้นช่างหลอกหลอนทว่าสวยงาม ชั่วขณะหนึ่งผมรู้สึกเหมือนในที่สุดผมก็ถอดรหัสได้แล้ว แต่...

*‘ไม่ มีบางอย่างขาดหายไป’*

มันยากที่จะอธิบาย แต่ในขณะที่มือของผมขยับและร่างกายบรรเลงไปตามจังหวะดนตรี ผมกลับรู้สึกถึงมันได้ชัดเจนยิ่งขึ้น มีบางอย่างที่ขาดหายไปอย่างเห็นได้ชัดในบทเพลงที่ผมกำลังเล่น ใจผมหล่นวูบ

*‘อะไรที่ขาดไป? มันไม่สมเหตุสมผลเลย ผมกำลังเล่นในแบบที่สมบูรณ์แบบที่สุดเท่าที่จะทำได้แล้วนะ มันจะมีอะไรขาดหายไปได้ยังไง?’*

ตึง, ตะ— ขณะที่นิ้วของผมไล่ไปตามคีย์และท่วงทำนองพรั่งพรูออกมาในอากาศ ผมค่อยๆ เงยหน้าขึ้นมองไปยังระยะไกล จากเงาสะท้อน ผมเห็นร่างลางๆ ของบางสิ่ง ร่างกายของมันถูกกลืนกินโดยเงามืด มีเพียงหน้ากากสีซีดที่ส่องประกายผ่านความมืด ท้องไส้ผมปั่นป่วน นั่นมัน—!

*ตึก*

ร่างนั้นก้าวเท้าไปข้างหน้า ร่างกายของผมเกร็งไปทั้งตัว แต่ถึงอย่างนั้น—

*ตึง!*

การเคลื่อนไหวก็ยังดำเนินต่อไป

*ตึก... ตัก! ตึก... ตัก!*

พวกมันก้าวเข้ามาอีกก้าว พวกมันขยับเข้ามาใกล้ผมมากขึ้น หน้ากากสีขาวว่างเปล่านั้นชัดเจนยิ่งขึ้น และในที่สุด พวกมันก็หยุดลงตรงหน้าผมพอดี

*‘ไม่ ไม่ ไม่...’*

ผมหยุด ปลดปล่อยตัวเองจากการสะกดจิตในขณะที่มือข้างหนึ่งกดลงไป และผมก็ยกมืออีกข้างขึ้น

*เต๊ง!*

แต่สายเกินไปแล้ว มือของพวกมันยกขึ้น เผยให้เห็นมีดยาวที่คมกริบ และ—

*ฉูด!*

เวลาถูกรีเซ็ต

“ฮว้าบบบ!”

ผมสะดุ้งตื่นขึ้นมา มือขยำหน้าอกขณะที่หายใจเข้าลึกและหนักหน่วง รู้สึกถึงความเจ็บปวดที่ยังคงหลงเหลืออยู่ในส่วนลึกของจิตใจอยู่พักใหญ่

“แฮ่ก... แฮ่ก...”

ผมกดมือลงบนหน้าอก พยายามอย่างเต็มที่เพื่อให้ตัวเองสงบลง

“ท-ทำไมกัน...?”

ผมใช้เวลาครู่หนึ่งเพื่อประมวลผลสิ่งที่เกิดขึ้น ผมนึกย้อนกลับไปถึงช่วงเวลาก่อนจะถึงวินาทีสุดท้าย ผมจำได้ว่าตัวเองเล่นยังไง แล้วก็ยกมือทั้งสองข้างขึ้นปิดหน้า

“มันไม่สมเหตุสมผลเลย เพลงของผมสมบูรณ์แบบมาก ทั้งตัวโน้ต ทุกๆ อย่าง... ไม่มีอะไรผิดพลาดในสิ่งที่ผมเล่นเลย มันไม่ควรจะมีอะไรขาดหายไปสิ แล้วทำไมถึงยังมีบางอย่างขาดหายไปล่ะ?”

ผมขยำผมตัวเองแน่นจนหนังศีรษะเริ่มแสบ

*‘คิดสิ คิด คิด คิด คิด คิด’*

ผมพลาดอะไรไป? ทำไมมันถึงไม่สมบูรณ์แบบทั้งที่มันสมบูรณ์แบบแล้ว?

*เต๊ง!*

ทำไม— ผมชะงักไปครู่หนึ่ง โน้ตตัวหนึ่งแวบเข้ามาในหัว เต๊ง โน้ตที่ผิดเพี้ยน แต่มันกลับเป็นสิ่งเดียวที่ผมจำได้จากการเล่นของผม ทำไมล่ะ? เพราะอะไรกัน? จู่ๆ ผมก็ลุกพรวดขึ้น

*ปัง!*

ผมผลักโต๊ะไปด้านข้างและปัดทุกอย่างลงบนพื้น ทำลายทุกอย่างที่ขวางหน้า **[ดรีมวอล์กเกอร์]** ออกมาทันที ช่วยผมพังทุกอย่างจนยับเยิน ก่อนที่ในที่สุดผมจะเดินออกจากห้องและโยนทุกอย่างทิ้งไป แล้วตั้งคีย์บอร์ดขึ้นมาใหม่เหมือนเดิม ผมสวมหน้ากากและนั่งลงบนเก้าอี้ การแจ้งเตือนปรากฏขึ้นเหมือนก่อนหน้านี้ ครั้งนี้ผมไม่ได้กดมัน แต่ผมหยุดนิ่งโดยที่มือยังวางอยู่บนคีย์บอร์ด ผมเงยหน้าขึ้นมองตัวตลกที่ปรากฏตัวตรงหน้า

“ทำให้ผมสามารถกลับมาควบคุมตัวเองได้ทุกเมื่อที่ต้องการ”

ตัวตลกไม่ได้พูดอะไร เพียงแค่พยักหน้า ผมหันกลับมามองคีย์บอร์ดและหลับตาลง ผมนึกย้อนกลับไปถึงบทเพลงนั้น มันเป็นเพลงที่วาทยกรสร้างขึ้น เป็นเพลงที่จังหวะจะเร็วขึ้นเรื่อยๆ ตามเวลาที่ผ่านไป เพลงที่แสดงออกถึงความสิ้นหวังที่มาพร้อมกับความสมบูรณ์แบบได้อย่างไร้ที่ติ ยิ่งเข้าใกล้ความสมบูรณ์แบบมากเท่าไหร่ ก็ยิ่งรู้สึกสิ้นหวังมากขึ้นเท่านั้น ผมเข้าถึงความสมบูรณ์แบบได้โดยใช้ **[มิสเตอร์จิงเกิลส์]** อย่างไรก็ตาม ผมยังคงขาดบางอย่างไป ในวินาทีสุดท้ายนั้น ตอนที่ฆาตกรต่อเนื่องปรากฏตัว

ผมก็ได้รู้ว่าสิ่งที่ผมขาดไปคืออะไร ความสิ้นหวัง อารมณ์ สิ่งที่ผมขาดไปคือแก่นแท้ของดนตรี และดังนั้น— ผมจึงเอื้อมมือไปหยิบตะเกียงดวงหนึ่ง

*คลิก!*

แสงสีฟ้าซีดปรากฏขึ้นทันทีหลังจากที่ผมเปิดมัน เสียงฝีเท้าดังขึ้นจากทุกทิศทาง และบรรยากาศรอบข้างก็เย็นเยียบลง น้ำหนักของการจ้องมองที่ซ่อนอยู่รุนแรงขึ้น และหัวใจของผมก็บีบรัดแน่นอยู่ในอก

“ความสิ้นหวัง ความสิ้นหวัง...”

ผมพึมพำคำเดิมซ้ำๆ เสียงของมิสเตอร์จิงเกิลส์กระซิบเข้ามาในหัวผมอีกครั้ง มือของผมเริ่มขยับไปเอง

*ตะ ตึง—*

ผมเริ่มเล่นบทเพลงที่สมบูรณ์แบบอีกครั้ง ตัวโน้ตไหลลื่นและไม่มีข้อผิดพลาด ผมไร้ที่ติ ผมสมบูรณ์แบบ และในไม่ช้า—

*ตึก*

เสียงฝีเท้าหนึ่งดังขึ้น และเมื่อผมเงยหน้าขึ้น ร่างสวมหน้ากากก็ปรากฏขึ้นในระยะไกล หัวใจของผมบีบรัดแน่น

*‘ไม่ ไม่ ไม่...’*

ความกลัวเริ่มกัดกินจิตใจของผม แต่ในขณะเดียวกัน ผลของการสะกดจิตก็แตกสลายลง ผมกลับมาควบคุมร่างกายได้โดยสมบูรณ์ แต่ถึงแม้จะควบคุมได้แล้ว ผมก็ไม่ได้หยุดเล่น

*ต๊อง!*

ผมเริ่มเล่นพลาด

*ต๊อง ตะ—*

ยิ่งร่างสวมหน้ากากเข้ามาใกล้มากเท่าไหร่ ผมก็ยิ่งเล่นพลาดมากขึ้นเท่านั้น

*ติ๊ง! เต๊ง! ตุง! แต๊ง! ตะ— เต๊ง!*

บทเพลงที่สมบูรณ์แบบได้แตกสลายลง และในไม่ช้า—

*ฉูด!*

ความตายของผมก็มาถึง

“ฮวัก!”

ผมสะดุ้งตื่น หัวสะบัดขึ้นขณะที่ดวงตากวาดมองไปรอบๆ อย่างลนลาน ผมเริ่มหายใจหอบถี่ขณะที่เหงื่อโชกไปทั้งตัว และใบหน้าของผมก็ซีดเผือดจนดูเหมือนผี

*‘จำไว้ จำไว้ จำไว้’*

ผมลุกขึ้นอย่างอ่อนแรง บังคับตัวเองให้นึกถึงวินาทีสุดท้าย ช่วงเวลาที่ร่างนั้นขยับเข้ามาใกล้ผม ช่วงเวลาที่ถูกมีดแทง ช่วงเวลาที่ผมเริ่มสิ้นหวัง ผมนึกถึงความรู้สึกนั้นก่อนจะเอามือปิดปาก

“อุแหวะ!”

แม้จะพยายามอย่างที่สุดแล้ว แต่อาเจียนก็ยังพุ่งออกมา ผมเอื้อมไปหยิบถังขยะใกล้ๆ แล้วเริ่มสำรอกทุกอย่างออกมา

“อ้วกกกก!”

รสกรดรุนแรงยังคงติดอยู่ในปากขณะที่ผมอ้วกจนหมดไส้หมดพุง สมองของผมว่างเปล่าไปชั่วขณะก่อนจะปล่อยมือและฝืนตัวลุกขึ้น เอื้อมไปหาคีย์บอร์ด ผมเดินไปที่ประตูทันที ดรีมวอล์กเกอร์ปรากฏตัวตามมา พังทลายและทำลายทุกอย่างที่ขวางหน้า ผมสวมหน้ากากและผลักประตูเปิดออก จัดวางหน้ากากและเริ่มใหม่อีกครั้ง แสงสลัวของตะเกียงปรากฏขึ้นอีกครั้ง

*ตะ, ตึง—*

ฆาตกรต่อเนื่องตามมาในไม่ช้า

*เต๊ง! ตุง! แต๊ง! ตะ— เต๊ง!*

ครั้งนี้ผมเล่นพลาดมากกว่าเดิมอีก

“ไม่ เดี๋ยวก่อน—!”

*ฉูด!*

ผมตายอีกครั้ง

“อ้วก!”

ผมอ้วกอีกครั้ง

*ฉูด!*

ผมตายอีกครั้ง

“อ้วก!”

ผมอ้วกอีกครั้ง

*ฉูด!*

ผมตายอีกครั้ง

“อ้วก!”

ผมอ้วกอีกครั้ง

วงจรนี้ดำเนินต่อไป ผมสูญเสียความเป็นตัวเองไปแล้ว ผมแค่ทำซ้ำวงจรเดิมซ้ำแล้วซ้ำเล่า บังคับตัวเองให้นึกถึงความรู้สึกสิ้นหวังที่เกิดขึ้นทุกครั้งที่ผมตาย ตั้งแต่วิธีที่ผมตายไปจนถึงความเจ็บปวดที่มาพร้อมกับมัน จำนวนการลูปพุ่งสูงถึงเลขสี่หลัก ในแต่ละครั้ง วงจรจะดำเนินซ้ำเดิม ผมตาย ผมอ้วก และผมบังคับตัวเองให้เล่น จิตใจของผมเสื่อมถอยลง ความบ้าคลั่งเริ่มเข้าครอบงำ

*‘เล่น! เล่น! เล่น! เล่น! เล่น!’*

*ตึง! ตึง—!*

ผลที่ตามมาคือ การเคลื่อนไหวของผมเริ่มผิดเพี้ยนและบ้าคลั่ง เค้าโครงของระเบียบและความสมบูรณ์แบบหายไปสิ้น ผมไม่ได้สมบูรณ์แบบอีกต่อไป ผมกำลังเล่นได้ห่วยแตกสิ้นดี แต่ถึงอย่างนั้น— เมื่อผมเงยหน้าขึ้นและจ้องมองไปยังผู้ชมที่ก่อตัวขึ้นโดยไม่รู้ตัว ในวินาทีนั้น ผมก็ได้เห็นมัน ความบ้าคลั่งของผม อารมณ์ของผม ความสิ้นหวังของผม ...สะท้อนอยู่ในแววตาของพวกเขา และนั่นคือตอนที่ผมตระหนักได้ว่า ในความบ้าคลั่งของผมนั้น ผมได้เข้าถึงความสมบูรณ์แบบแล้ว
