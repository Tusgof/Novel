# ตอนที่ 273 - เคลียร์ง่าย [3]

*เดี๋ยว เดี๋ยว เดี๋ยว...*

คลาราขยี้หัวตัวเอง โลกที่อยู่รอบกายเริ่มเอียงกะเท่เล่เมื่ออาการไมเกรนที่แหลมคมเริ่มกดทับเข้ามา ความเจ็บปวดพองโตจนทัศนวิสัยของเธอพร่ามัว และชั่วขณะหนึ่งการทรงตัวของเธอก็พังทลาย ทำให้เธอเดินโซเซด้วยเท้าที่ไม่มั่นคง

“เฮ้ เฮ้...!” ถ้าไม่ได้หัวหน้าแผนกช่วยพยุงไว้ เธอคงล้มพับไปแล้ว “คุณโอเคไหม? หน่วยแพทย์—”

“ไม่ ฉันไม่เป็นไร อย่าเรียกพวกเขาเลย มันจะทำให้สถานการณ์แย่ลง อีกไม่กี่นาทีฉันก็คงดีขึ้น”

คลาราขยี้หัวอีกครั้ง พยายามฝืนผลักความเจ็บปวดออกไปขณะที่รวบรวมสติ แม้จะพยายามอย่างเต็มที่แล้ว แต่ความเจ็บปวดนั้นรุนแรงมาก เธอใช้เวลาทั้งหมดสิบนาทีกว่าจะกลับมาเป็นปกติอย่างสมบูรณ์ขณะที่นั่งลงบนพื้น พลางกระดกน้ำดื่มขวดที่หัวหน้าแผนกหามาให้

“รู้สึกดีขึ้นหรือยัง?” เมื่อได้ยินคำพูดของหัวหน้าแผนก คลาราก็พยักหน้า “...ค่ะ นิดหน่อย” อาการไมเกรนไม่เจ็บเท่าเดิมแล้ว แต่มันยังคงอยู่ วนเวียนอยู่ที่ส่วนลึกของความคิด

“โอเค พักผ่อนเถอะ ถึงผมจะอยากถามเรื่องสถานการณ์มากกว่านี้ แต่เอาไว้ทีหลังก็ได้ เดี๋ยวผมจะไปคุยกับพวกเจ้าหน้าที่ก่อน ถ้าต้องการอะไรก็ส่งข้อความหาผมหรือเรียกได้เลย”

เมื่อเห็นว่าเธอดูดีขึ้นแล้ว หัวหน้าแผนกจึงตัดสินใจให้ความเป็นส่วนตัวกับเธอ โดยเขาลุกขึ้นและเดินไปตรวจสอบผู้เล่นใหม่คนอื่นๆ พร้อมกับคุยกับเจ้าหน้าที่สำนักงาน

สายตาของคลารามองตามเงาร่างของเขาไปครู่หนึ่งก่อนจะหลับตาลงและคิดทบทวนถึงสถานการณ์ที่เกิดขึ้น

*จำนวนคนที่พวกเราต้องช่วยคือสิบเอ็ดคน ฉันมั่นใจ* พวกเขาได้รับข้อมูลประวัติของคนที่ต้องช่วยล่วงหน้ามาหมดแล้ว เธอมั่นใจในข้อเท็จจริงนี้ *...ในวินาทีสุดท้าย ฉันนับได้สิบหกคน พวกเราควรจะมีกันแค่สิบห้าคนสิ*

เธอเผลอนับตัวตลกไปด้วยหรือเปล่า? *ไม่ ไม่น่าใช่ ตัวตลกเข้าไปก่อนหน้านั้นแล้ว* ถ้าอย่างนั้น... *มีคนเกินเข้ามางั้นเหรอ?*

คลารากลืนน้ำลายอย่างเงียบเชียบ รู้สึกได้ว่าขนบนผิวหนังเริ่มลุกชันขณะที่ความเย็นเยือกกดทับลงบนแผ่นหลัง ใคร...? ใครกันที่อาจจะแอบเข้ามา?

คลารากลืนน้ำลายอีกครั้ง แม้จะอยู่ในสถานการณ์ที่วุ่นวาย แต่เธอเกือบจะมั่นใจว่าเธอและทีมควรจะรู้ตัวหากมีคนเกินมา ความจริงแล้วเธอไม่ใช่คนประเภทที่จะลืมเรื่องง่ายๆ อย่างการที่มีคนรวมกันทั้งหมดสิบหกคน ปกติแล้วเธอต้องรู้ตัวว่ามีคนเกินมา การที่เธอไม่สังเกตเห็นเลยมันไม่สมเหตุสมผลสำหรับเธอ

นี่เป็นความผิดพลาดเพราะความเหนื่อยล้า? หรือว่า... มันมีอะไรมากกว่านั้น?

*ไม่ว่าจะคิดยังไง ฉันก็นึกไม่ออกเลยว่ามีใครที่ฉันไม่รู้จักอยู่ในห้องนั้นบ้าง* คลาราภูมิใจในความจำของตัวเอง เธอสามารถจำใบหน้าทุกคนในห้องได้อย่างชัดเจน ทว่า— กลับไม่มีใบหน้าไหนเลยที่เธอไม่คุ้นเคย

*มันจะเป็นไปได้ยังไง?* ยิ่งคลาราคิดถึงเรื่องนี้มากเท่าไหร่ อาการไมเกรนที่วนเวียนอยู่หลังหัวก็เริ่มกลับมาอีกครั้ง และท่ามกลางความคิดเหล่านั้นเองที่เธอก้มหน้าลงและจ้องมองกล้องตัวเล็กๆ ที่ติดอยู่บนเครื่องแบบ

*โชคดีที่ฉันติดไอ้นี่ไว้* คลาราหันไปมองทางหัวหน้าแผนก เขายังคงยุ่งอยู่กับการคุยกับพวกเจ้าหน้าที่สำนักงาน เธอเม้มริมฝีปากเงียบๆ ก่อนจะหยิบโทรศัพท์ออกมาและเปิดแอปกิลด์ขึ้นมา จากนั้นเธอก็เชื่อมต่อโทรศัพท์เข้ากับกล้อง

วิดีโอเริ่มเล่นหลังจากนั้นไม่นาน มันเป็นวิดีโอที่ยาวมาก โชคดีที่คลาราต้องการดูแค่ตอนจบ เธอจึงข้ามไปยังช่วงเวลานั้นทันที

*ตรงนี้แหละ* เธอหยุดตรงส่วนที่เธอจำได้พอดี ก่อนที่เธอจะเริ่มวิ่งไปที่ประตู ในวินาทีนั้น เธอเห็นมันอย่างชัดเจน ร่างทั้งสิบหกที่เธอจำได้ว่านับไว้

*นึกแล้วเชียว ไม่ได้ตาฝาดไปจริงๆ ด้วย* หัวใจของเธอเต้นรัวอยู่ครู่หนึ่ง จากนั้นเธอก็กดเล่นต่อ วิดีโอดำเนินไป

—วิ่ง! เร็วเข้า!
—อย่าล้าหลัง! รีบวิ่งเร็ว!

เธอได้ยินเสียงอู้อี้ของตัวเองจากในวิดีโอ เสียงฝีเท้าที่ตามหลังเธอมาด้วย เธอได้ยินทั้งหมด แต่นั่นไม่ใช่สิ่งที่เธอสนใจ สิ่งที่เธอสนใจคือคนทั้งสิบหกคนนั้น คลารามองไปที่แผ่นหลังของพวกเขาทุกคน และพบว่าตัวเองไม่สามารถบอกได้ว่าใครคือคนที่เกินมา ทุกคนดูคุ้นหน้าคุ้นตาเธอไปหมด ทำไมกัน...?

คลาราเร่งความเร็ววิดีโอ มันเป็นช่วงเวลาหลังจากที่เธอเข้าไปในห้องได้ไม่นาน เธอเห็นเงาขนาดมหึมาทอดลงข้างหลังเธอ มือที่ค่อยๆ เงื้อขึ้นเพื่อจะแทงเธอ เธอได้ยินเสียงลมหายใจของตัวเองที่ขาดห้วง และร่างกายที่เกร็งเครียด แต่มันก็เป็นจังหวะนั้นเองที่เธอเห็นใบหน้าของทุกคนที่อยู่ที่นั่น

คลารานับอีกครั้ง *หนึ่ง สอง สาม... เจ็ด แปด... สิบสอง สิบสาม... สิบหก* อยู่กันครบทุกคน

คลาราหยุดวิดีโอไว้ตรงนั้นและเงยหน้าขึ้นมองไปในระยะไกล ตรงที่คนอื่นๆ อีกสิบห้าคนรวมตัวกันอยู่ เธอเริ่มจับคู่ใบหน้าของพวกเขากับคนในวิดีโออย่างช้าๆ

*เขาอยู่นี่ เธออยู่นี่ เขาอยู่นี่ เขา...* เสียงของเธอหยุดลง

ชายหนุ่มที่มีกระ ผมสีดำ และดวงตาสีน้ำตาลเข้ม... เขาไม่ได้อยู่ในกลุ่มที่อยู่ตรงนั้น

ลำคอของคลาราตีบตันขณะที่เธอจ้องมองเขา เขาไม่ได้อยู่ในกลุ่มที่อยู่ตรงนั้น ไม่เหมือนในวิดีโอ คลารามองกลับไปที่มัน เธอรู้สึกมั่นใจว่าเธอรู้จักเขา แต่ทว่า... ยิ่งเธอจ้องนานเท่าไหร่ เธอก็ยิ่งไม่แน่ใจมากขึ้นเท่านั้น ผิวหนังของเธอเริ่มซ่านสยอง หน้าอกรัดแน่น และอากาศรอบตัวเริ่มรู้สึกอึดอัด ลมหายใจของเธอเริ่มถี่กระชั้น

โดยไม่รู้ตัว นิ้วของเธอเผลอกดปุ่ม ‘เล่น’

เด็กหนุ่มคนนั้นหันหัวมา ดวงตาของเขาจ้องล็อคมาที่กล้อง และจากนั้น เขาก็ค่อยๆ ยิ้มออกมา

“อ้วก!”

ทันทีที่ผมได้สติ สิ่งแรกที่ผมทำคืออ้วกใส่ถังขยะที่ใกล้ที่สุด

“อ้วกกก—!”

แม้จะพยายามกลั้นไว้อย่างสุดความสามารถ แต่ผมก็หยุดตัวเองไม่ได้ กระเพาะของผมทำงานไปเองขณะที่ผมเริ่มอ้วกเอาวิญญาณทั้งหมดออกมา ความบอบช้ำและประสบการณ์ทั้งหมดจากเกตโถมเข้าใส่ผมพร้อมกันในคราวเดียวขณะที่ผมเริ่มอ้วก ผมคิดว่าผมชินกับมันแล้วหลังจากผ่านอะไรมาตั้งมากมาย แต่ผมคิดผิด ครั้งนี้มันแย่ยิ่งกว่าเดิม ผมไม่ได้อ้วกเพราะความกลัว แต่เป็นเพราะความบอบช้ำทางจิตใจ จิตใจของผมแค่กำลังพยายามอย่างเต็มที่เพื่อฟื้นคืนตัวตนของผมกลับมา

“แฮ่ก... แฮ่ก...”

ผมไม่รู้ว่าตัวเองอ้วกไปนานแค่ไหน พอหยุดได้ ผมก็รู้สึกอ่อนแรงอย่างถึงที่สุดจนทรุดลงกับพื้น ผมจ้องมองเพดานข้างบนอย่างว่างเปล่า แสงไฟกะพริบเบาๆ

...ผมเริ่มเบื่อภาพข้างบนนี้แล้ว ผมเห็นมันมาบ่อยเกินไป

“แฮ่ก—”

การอ้วกไม่ใช่ส่วนที่แย่ที่สุด ส่วนที่แย่ที่สุดคือการพยายามแยกจิตใจออกจากทุกสิ่งที่เกิดขึ้น ตอนนี้ทุกอย่างดูชาไปหมด นิ้วมือของผมสั่นกระตุก และอารมณ์ของผมก็ปั่นป่วนไปหมด ผมเข้าใจดีว่ามันต้องใช้เวลาสักพักกว่าผมจะกลับเป็นปกติ

ผมฝืนตัวลุกขึ้น หยิบโทรศัพท์ออกมาเช็กวันที่ ตอนอยู่ในเกตผมไม่รู้เลยว่าเป็นวันอะไร แต่ตอนนี้ที่ออกมาแล้ว เรื่องนี้ไม่ควรเป็นปัญหาอีกต่อไป

*หวังว่าคงไม่นานเกินไปนะ หวังว่า—*

หัวใจของผมหล่นวูบทันทีที่เลื่อนดูปฏิทิน ยี่สิบวัน รวมทั้งหมดสิบยี่สิบวันผ่านไปนับตั้งแต่ที่นาฬิกาทรายถูกพลิก หัวใจของผมจมดิ่งเมื่อตระหนักได้ ผมจึงฝืนลุกขึ้นและเชื่อมต่อโทรศัพท์กับ Wi-Fi

“ฉิบหายแล้ว...”

ยิ่งคิดถึงสถานการณ์นี้ ผมก็ยิ่งกังวล ผมหายตัวไปรวมยี่สิบวัน ผมเกือบจะมั่นใจว่ากิลด์ต้องเริ่มตามหาผมแล้ว ไคล์ก็คงเหมือนกัน เผลอๆ อาจจะมีการตามล่าตัวกันเลยด้วยซ้ำ

*หน้าผมอาจจะหราอยู่บนหน้าหนังสือพิมพ์ทุกฉบับแล้วก็ได้*

ผมกัดเล็บขณะเชื่อมต่อโทรศัพท์กับอินเทอร์เน็ต และในขณะที่ผมเริ่มจะสติแตก ผมก็ชะงักไป

“เอ๊ะ...?”

ไม่มีข้อความถาโถมเข้ามาอย่างที่คาดไว้ แต่มันกลับเงียบเชียบอย่างประหลาด ผมเปิดเบราว์เซอร์และค้นหาชื่อตัวเอง นอกจากเรื่องเกมของผมสองสามอย่างแล้ว ก็ไม่มีอะไรเลย

“เดี๋ยว อะไรนะ?” ผมเกาข้างแก้ม “สรุปคือไม่มีใครรู้ตัวเลยเหรอ?”

ผมขมวดคิ้วมองโทรศัพท์ ตรวจสอบซ้ำอีกครั้งเพื่อให้แน่ใจ แต่มันดูเหมือนว่าจะไม่มีใครสังเกตเห็นการหายตัวไปยี่สิบวันของผมจริงๆ นี่มัน...

“ผมไม่ได้เป็นพวกไร้ตัวตนในสังคมขนาดนั้นใช่ไหม?”
