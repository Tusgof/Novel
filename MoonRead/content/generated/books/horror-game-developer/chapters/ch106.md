# ตอนที่ 106 - คนเชือด [1]

*เพล้ง!*

กระจกแตกกระจายไปทั่วทุกทิศทาง เศษแก้วคมกริบหมุนคว้างในอากาศ ขณะที่มือแห้งกรังราวมัมมี่ตะเกียกตะกายผ่านกรอบหน้าต่างที่แตกเข้ามา ความคิดของผมแตกซ่านไม่แพ้กัน ความตื่นตระหนกพุ่งพล่าน ผมรีบก้มมองลงไปทันที เงาร่างที่เคยอยู่ตรงนั้นเมื่อไม่กี่วินาทีก่อนหายไปแล้ว อันตรธานไร้ร่องรอย แสงจันทร์สาดส่องผ่านช่องว่างของหน้าต่าง ทอดเงาหลายสายท่ามกลางความโกลาหล ความหนาวเยือกแล่นพล่านไปตามกระดูกสันหลัง มันเคลื่อนที่ไปแล้วเหรอ? ตอนนี้มันเข้ามาใกล้กว่าเดิมใช่ไหม? หรือที่แย่กว่านั้น... มันกำลังเฝ้าดูอยู่?

ความเงียบอันน่าสะพรึงกดทับลงมาครู่หนึ่ง มันหนักอึ้งและ... ชวนอึดอัด ผมแทบรู้สึกได้ว่ามีบางอย่างกำลังหายใจอยู่ตรงขอบหน้าต่าง กำลังมองหาบางอย่าง มองหา... ผม แต่ในขณะเดียวกัน มันกลับรู้สึกเหมือนกำลังมองหาอย่างไร้จุดหมาย ราวกับมันไม่สามารถระบุตำแหน่งของผมได้แน่ชัด ความคิดหนึ่งแล่นเข้ามาในหัวตอนนั้น

*...เดี๋ยวก่อน หรือว่าเพราะเสียงดังพวกนี้ มันถึงมองไม่เห็นผม?*

คิ้วของผมเลิกขึ้นเมื่อคิดได้แบบนั้น มันสมเหตุสมผล! *ด้วยเสียงทั้งหมดที่เกิดขึ้นรอบๆ มันคงยากที่มันจะตรวจพบผม มันเลยตัดสินใจส่งพวกศพพวกนี้มาโจมตีอะไรก็ตามที่อยู่ในสายตาโดยตรง!*

*เพล้ง เพล้ง!*

ความดีใจช่างสั้นนัก เมื่อเห็นกระจกแตกเพิ่มขึ้นและมีมือโผล่ออกมามากขึ้น หัวใจของผมหล่นวูบ พวกมันกำลังเพิ่มจำนวน คลานเข้ามาจากทุกทิศทาง ในขณะที่ตัวหนึ่งอาจถูกจัดการไปแล้ว อีกตัวก็โผล่มา มันไม่มีที่สิ้นสุด ผมรีบกวาดสายตามองรอบๆ หวังจะหาทางออกสักทาง แต่หัวใจก็จมดิ่งเมื่อเห็นว่าศพแห้งกรังประหลาดพวกนี้กำลังมาจากทุกทิศทาง ทำให้ผมไม่มีช่องว่างให้หนีเลย

*ทำยังไงดี?* ลมหายใจของผมเริ่มหอบถี่ และเมื่อมองรอบๆ ผมก็รู้สึกถึงความไม่สบายใจที่ก่อตัวขึ้นในท้อง *เอาละ เอาละ เอาละ!* ผมกัดริมฝีปากจนเลือดซึมเพื่อให้คิดได้ชัดเจนขึ้น *ไม่ ฉันต้องใจเย็นลง จะมาสติแตกตอนนี้ไม่ได้*

สัญชาตญาณนักพัฒนาเกมของผมทำงานขึ้นมาทันที แม้จะมีความกลัวท่วมท้นที่กำลังรู้สึกอยู่ แต่ผมก็ยังจัดการหาเหตุผลให้กับสถานการณ์ของตัวเองได้ ในที่สุด สายตาของผมก็เหลือบไปเห็นทิศทางหนึ่ง บันได! *ผมไม่ได้ยินเสียงอะไรมาจากข้างบนเลย หมายความว่าไม่มีสิ่งมีชีวิตประหลาดมาจากทางนั้น* แถมบันไดยังแคบพอที่จะทำให้ผมไม่ถูกพวกตัวอะไรก็ตามพวกนั้นล้อมกรอบได้

*เพล้ง!* “.....!” เมื่อเห็นหน้าต่างอีกบานแตก ผมไม่ลังเลที่จะพุ่งตัวไปที่บันได ก่อนจะหยุดและหันกลับมาเมื่อร่างหนึ่งพุ่งตรงมาหาผมอย่างรวดเร็ว โดยไม่คิดอะไรมาก ผมปิดการเชื่อมต่อของกล้อง และสีหน้าของผมก็เปลี่ยนไปเมื่อเห็นมันพุ่งเข้าใส่ ผมเตรียมพร้อม กัดฟันแน่นและเกร็งตัว ก่อนจะปักมีดลงไปที่กะโหลกของมัน

*ฉึก!*

เหล็กกล้าปะทะกับกระดูกที่เปราะบางจนเกิดเสียงแตกหัก แรงกระแทกสะท้อนผ่านแขนของผมขณะที่ใบมีดปักลึกเข้าไปในกะโหลกของสิ่งมีชีวิตนั้น ก่อนที่ผมจะทันประมวลผลเสียงล้มลงแผ่วเบาของมัน ผมก็กระชากมีดออกมาและถอยหลังกะเผลก ถุงเท้าลื่นไถลบนพื้นไม้ที่แตกเป็นเสี่ยงๆ ในเวลาเดียวกัน สิ่งมีชีวิตแห้งกรังอีกตัวก็พุ่งเข้ามาหา ผมรีบชูมีดขึ้นกลางอากาศและแทงลงไปอีกครั้ง

*ฉึก!*

ผลลัพธ์เหมือนเดิม พวกมันจัดการไม่ยากนัก แต่... มันมีเยอะเกินไป ท้องไส้ของผมปั่นป่วนเมื่อเห็นว่ามีพวกมันมากแค่ไหน โชคดีที่ก่อนสถานการณ์จะแย่ไปกว่านี้ ร่างหนึ่งก็ปรากฏขึ้นตรงหน้าผม มือของมันเคลื่อนไปข้างหน้าเพื่อสร้างโล่บางอย่าง ผมยืนนิ่งอยู่พักหนึ่ง จ้องมองสิ่งมีชีวิตที่พยายามจะผ่าน ดรีมวอล์กเกอร์ เข้ามา ในที่สุด ผมก็ก้มหน้าลงจ้องมองมีด กำด้ามแน่นและยื่นมันไปข้างหน้า

*รีบๆ ตายไปซะก่อนที่ผมจะอ้วกแตก!*

“ตรวจพบอะไรผิดปกติไหม?”

“ไม่.... ยังเช้าอยู่เลย” เรย์มอนด์ส่ายหัว มองไปยังระยะไกลด้วยดวงตาที่หรี่ลง ดวงตาของเขาที่ปกติเป็นสีน้ำตาล ตอนนี้กลายเป็นสีแดงเข้มขณะที่สายตาหยุดพักครู่หนึ่งบนถนนที่รกร้างและบ้านเน่าเปื่อยที่ว่างเปล่า อากาศอับชื้น และความเงียบที่ตอบกลับมานั้นให้ความรู้สึกตึงเครียด เรย์มอนด์เลียริมฝีปากก่อนจะพูดอีกครั้ง

“ฉันไม่สังเกตเห็นอะไรเลย ทุกอย่างดูและรู้สึกเหมือนเดิม ไม่มี... อะไรอยู่ใกล้เราเลย”

“นายแน่ใจนะ?”

เรย์มอนด์หันไปหาโซอี้ก่อนจะพยักหน้า “ใช่ ฉันค่อนข้างมั่นใจ” เขาค่อนข้างมั่นใจในความสามารถของเขาในการตรวจจับความผิดปกติในสภาพแวดล้อม แม้ว่าเขาจะยังห่างไกลจากคำว่าเก่งที่สุด แต่เขาก็ยังดีพอที่จะอยู่ในหน่วยระดับหัวกะทิ ไม่มีสิ่งใดรอดพ้นสายตาเขาไปได้มากนักขณะที่เขามองไปยังระยะไกลที่ถนนสิ้นสุดลง และมีป่าทึบขนาดใหญ่มาแทนที่ ฝีเท้าของเขาหยุดลง

“ฉันสัมผัสได้ว่านักโทษอยู่ทางทิศนั้น ถ้าให้ฉันเดา เขาคงหนีไปที่นั่นหลังจากพ่นอะไรบางอย่างออกมา” ขณะที่ดวงตาของเรย์มอนด์เปล่งประกายสีแดงเข้มขึ้น เขาก็สามารถยืนยันความคิดของเขาได้เมื่อเห็นเงาร่างในระยะไกล เดินไปมาอย่างไร้จุดหมาย “ไปกันเถอะ เขาอยู่ไม่ไกลจากเรา ไปรับตัวเขาแล้วออกไปจากที่นี่กัน ที่นี่ทำให้ฉันขนลุก”

ขณะที่เรย์มอนด์พึมพำคำเหล่านั้น เขาก็เคลื่อนที่ไปข้างหน้าโดยมีไคล์และคนอื่นๆ เดินตามมาด้านข้าง

*สวบสาบ~*

เมื่อเข้าสู่ป่า แสงไฟหลายลำก็ส่องสว่างไปทั่ว นำทางไปข้างหน้าขณะที่เรย์มอนด์นำพวกเขาไปหานักโทษ เรย์มอนด์เคลื่อนที่ไปข้างหน้าด้วยความเงียบเชียบที่น่าขนลุก ทุกย่างก้าวถูกกลบด้วยมอสและซากเน่าเปื่อยเบื้องล่าง จากนั้นเขาก็ชะงัก ดวงตาของเขากวาดมองป่าด้วยความหวาดระแวงอย่างลึกซึ้ง คิ้วของเขาขมวดมุ่นด้วยความตึงเครียดขณะที่สายตาจับจ้องไปยังบางอย่างที่อยู่ถัดจากต้นไม้ไปไม่กี่ต้น

“มีอะไรผิดปกติ? ทำไมเราถึงหยุด?” เมื่อคนหนึ่งในหน่วยถาม เรย์มอนด์ไม่ได้ตอบทันทีขณะที่เขายังคงจับจ้องไปที่เงาร่างในระยะไกลอย่างแน่วแน่ แวบแรกมันดูเหมือนต้นไม้ต้นหนึ่งในบรรดาต้นไม้มากมายที่ล้อมรอบพวกเขา อย่างไรก็ตาม มันไม่เหมือนต้นอื่นๆ... ต้นไม้ต้นนี้ดูเหมือนจะเคลื่อนที่มาทางพวกเขา บางอย่างเกี่ยวกับมันทำให้เขารู้สึกไม่ชอบมาพากลเมื่อได้มองใกล้ๆ และเมื่อพุ่มไม้ข้างหน้าขยับ สีหน้าของเขาก็เปลี่ยนไปทันทีเมื่อเขาตระหนักถึงบางอย่าง

ต้นไม้นั่น... ไม่ใช่ใครอื่นนอกจากนักโทษคนนั้น เขาเปลี่ยนไปจากที่เขาจำได้ครั้งล่าสุด เขาตัวสูงกว่าที่ควรจะเป็นมาก ไม่เพียงเท่านั้น หลังของเขายังค่อม และเมื่อแสงไฟสาดไปทางเขา ดวงตาที่ว่างเปล่าและไร้วิญญาณคู่หนึ่งก็ปะทะกับสายตาของพวกเขา ขณะที่ร่างกายทั้งหมดของนักโทษบิดเบี้ยวในลักษณะที่ทำให้ดูเหมือนต้นไม้บางชนิด

“นี่มันตัวอะไร...”

ก่อนที่คนอื่นๆ จะทันประมวลผลสถานการณ์ ไคล์ก็ก้มหน้าลงจ้องมองสร้อยข้อมือขนาดเล็ก และสีหน้าของเขาก็เปลี่ยนไปทันที

*ตื๊ด!*

“ฉิบหายแล้ว!”

คนอื่นๆ ต่างหันมามองเขา “เกิดอะไรขึ้น?”

“เกิดอะไรขึ้น? ทำไมทำท่าทางแบบนั้น?”

ไคล์ไม่ตอบขณะที่เขามองไปที่สร้อยข้อมือในมือ ในที่สุด เมื่อเงยหน้าขึ้น เขาก็มองคนอื่นๆ ด้วยความตื่นตระหนก “บ้านของฉันถูกบุกรุก! ตรวจพบความผิดปกติหลายอย่างที่นั่น!”

ใบหน้าของคนอื่นๆ เปลี่ยนไปทันทีขณะที่ไคล์หันหลังและพุ่งตรงกลับไปที่บ้าน หัวใจของเขาเต้นระรัวอยู่ในอก *บ้าเอ๊ย บ้าเอ๊ย บ้าเอ๊ย...! เป็นไปได้ยังไง? ฉันอุตส่าห์ตรวจเช็กทุกอย่างล่วงหน้าแล้วนะ มันไม่ควรจะมีอะไรสิ ทำไมจู่ๆ มันถึงโผล่มาจากไหนไม่รู้? นี่มันไม่สมเหตุสมผลเลยสักนิด!*

ไคล์ตื่นตระหนกกับสถานการณ์นี้อย่างมาก อย่างไรก็ตาม เขาต้องสะกดความตื่นตระหนกนั้นไว้และรีบพุ่งไปยังที่นั่น เซธกำลังตกอยู่ในอันตราย! ในฐานะมนุษย์ธรรมดา เขาไม่มีทางสู้ได้เลย *ไม่ ไม่ ไม่... ขอให้ปลอดภัยทีเถอะ* ไคล์รู้สึกเหมือนมีก้อนเนื้อขนาดใหญ่ก่อตัวขึ้นในท้องขณะที่เขาพุ่งไปข้างหน้า จนกระทั่งในที่สุดก็มองเห็นบ้านในระยะไกล คนอื่นๆ ตามหลังเขามาติดๆ ฝีเท้าของพวกเขารวดเร็วพอๆ กับไคล์ แต่ใบหน้าของเขาก็เปลี่ยนไปเมื่อเห็นหน้าต่างทุกบานของที่นั่นแตกกระจาย

“ไม่!” เขาตะโกนด้วยความตื่นตระหนก พุ่งไปข้างหน้า

*ปัง!*

เขากระแทกประตูเปิดออกและเข้าไปในบ้าน มองหาเซธอย่างบ้าคลั่งจนกระทั่ง... สายตาของเขาจับจ้องไปที่ร่างที่อยู่กลางห้อง: ศพนอนเกลื่อนกลาดอยู่ที่เท้าของเขา ร่างกายของพวกมันไม่ตอบสนองโดยสิ้นเชิง ในมือของเขามีมีดคมกริบเป็นประกาย เลือดของเหยื่อรายล่าสุดยังคงหยดลงมา ไคล์ชะงักอยู่กับที่ รู้สึกถึงความหนาวเยือกที่แล่นผ่านร่างกาย คนอื่นๆ ก็เช่นกัน

และแล้ว—

ร่างนั้นก็ค่อยๆ หันศีรษะมา สบสายตากับพวกเขา เผยให้เห็นร่างที่คุ้นเคยเป็นอย่างดี

“โอ้” เขาพูด เสียงแหบพร่าเล็กน้อย “...พวกคุณมาแล้วเหรอ”
