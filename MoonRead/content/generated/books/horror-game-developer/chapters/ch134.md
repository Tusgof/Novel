# ตอนที่ 134 - ภาพถ่าย [5]

ความเงียบเข้าปกคลุมทันทีหลังจากที่ผมปิดประตู แต่มันก็อยู่ได้ไม่นาน

*กริ๊ก กริ๊ก กริ๊ก*

ลูกบิดประตูเริ่มหมุนและส่งเสียงดังขณะที่ผมรู้สึกว่ามันถูกบิดไปทางซ้ายทีขวาที ยายแก่คนนั้นกำลังพยายามพังเข้ามา เมื่อนึกถึงพละกำลังมหาศาลของเธอ ผมก็รู้ได้ทันทีว่าอีกไม่นานประตูนี้ต้องพังแน่... หรืออย่างน้อย นั่นคือสิ่งที่ผมคิดในตอนแรก

“.....”

หลังจากพยายามอยู่สองสามครั้ง เสียงกริ๊กก็หยุดลง และจากนั้น—

*ตึก! ตึก!*

ผมได้ยินเสียงฝีเท้าที่แผ่วเบาลงขณะที่เธอเริ่ม... เดินจากไป?

*เธอไปแล้วเหรอ?* ตอนแรกผมทำตัวไม่ถูก แต่พอนึกถึงสิ่งที่เคยเกิดขึ้นก่อนหน้านี้ ผมก็เข้าใจว่ามันน่าจะเป็นกับดัก ผมจะไม่หลงกลซ้ำสองแน่ ผมจึงหันไปให้ความสนใจกับหน้าต่างที่อยู่ไกลออกไปและมุ่งหน้าไปทางนั้นโดยไม่หยุดพัก

*แต่ก็นะ... สกปรกชะมัด แม้แต่ห้องของเธอก็ยังแย่พอๆ กัน*

ขยะเกลื่อนกลาดอยู่บนพื้นอีกแล้ว คราวนี้มันแย่ยิ่งกว่าห้องนั่งเล่นข้างล่างเสียอีก ผมต้องก้าวเท้ากว้างๆ เพื่อที่จะเดินเลี่ยงกองขยะไปได้ ถึงตอนนี้ผมเริ่มชินกับกลิ่นเหม็นแล้ว มันเลยไม่ทำให้ผมกังวลอีกต่อไป เมื่อมาถึงหน้าต่าง ผมเคาะกระจกหนึ่งครั้งก่อนที่ของเหลวสีดำเหนียวข้นจะเคลือบมันไว้จนกลายเป็นค้อน

ผมก้าวถอยหลังเตรียมจะพังหน้าต่าง แต่แล้ว... ผมก็ชะงักและมองออกไปนอกหน้าต่าง

ดวงตาที่กลวงโบ๋คู่หนึ่งจ้องตรงมาที่ผม และผมก็แข็งทื่ออยู่กับที่

“....อา”

คนที่ยืนอยู่ข้างนอกหน้าต่างและมองขึ้นมาที่ผมจากด้านล่างคือยายแก่คนนั้น เธอชูตะเกียงขึ้นขณะจ้องมองมา ความหวาดกลัวที่เงียบงันเข้าเกาะกุมหน้าอกของผมขณะที่ผมก้าวถอยหลัง

*สรุปว่าไม่ใช่กับดักเหรอ? เสียงฝีเท้าเป็นของจริงงั้นเหรอ? เธอออกไปแล้วลงไปข้างล่าง? แต่ทำไมมันเร็วนัก...*

ผมรู้สึกว่าริมฝีปากสั่นขณะก้าวถอยหลังไปอีกก้าว

“อ๊ะ? อึก...!”

แต่ในตอนนั้นเองที่ผมรู้สึกว่ามีบางอย่างเกี่ยวข้อเท้าไว้จนผมสะดุดล้มหงายหลัง กองขยะช่วยรองรับแรงกระแทกจากการล้ม แต่เมื่อผมก้มลงมองดูว่าอะไรที่ทำให้ผมสะดุด ก้อนแข็งๆ ก็จุกขึ้นมาที่ลำคอ — ผมกำลังจ้องมองสิ่งที่ดูเหมือนมือที่เหี่ยวแห้งและแห้งกรัง

*มือเหรอ...?*

“ฉ-ฉิบหายแล้ว”

ยิ่งมองนานเท่าไหร่ ผมก็ยิ่งมั่นใจมากขึ้นเท่านั้น หัวใจของผมเต้นระรัวกระแทกซี่โครงแรงมากจนรู้สึกเหมือนมันพยายามจะหนีออกมา แต่นั่นยังไม่ใช่ทั้งหมด เมื่อมองดูที่มือนั้นดีๆ ผมก็เห็นชุดสูทที่ดูคุ้นตา และแม้ว่าทุกส่วนในร่างกายจะกรีดร้องให้ผมหนีไปให้ห่าง แต่ผมก็ยื่นมือที่สั่นเทาไปปัดกองขยะรอบๆ ศพออกเพื่อเผยให้เห็นร่างนั้น

“นี่มัน...”

ภาพที่ปรากฏแก่สายตาหลังจากที่ผมทำแบบนั้นทำให้ผมเป็นอัมพาตไปชั่วขณะ ผมเอามือปิดปากแล้วลุกขึ้นยืน ศพนี้เหมือนกับเหยื่อรายอื่นๆ ของชายบิดเบี้ยว มันแห้งกรังจนดูเหมือนร่างกายถูกสูบเลือดออกไปจนหมด ในขณะที่ดวงตาของมันยังคงกะพริบช้าๆ และปากก็เปิดปิดอย่างช้าๆ

*นั่น... มันยังมีชีวิตอยู่!*

แต่นั่นไม่ใช่ส่วนที่น่าขนลุกที่สุด ส่วนที่น่าขนลุกที่สุดคือสิ่งที่ศพสวมใส่ มันคือหมวกทรงสูงและชุดสูทแบบเดียวกับชายบิดเบี้ยว

“เรื่องอะไรกันเนี่ย...”

ผมกลืนน้ำลายแล้วหันไปสนใจรูปถ่ายในมือ และยืนยันได้ว่ามันเป็นเสื้อผ้าชุดเดียวกันจริงๆ แต่ในขณะเดียวกัน ผมก็สังเกตรูปถ่ายอีกใบที่วางอยู่ข้างศพ ผมลังเลอยู่ครู่หนึ่งก่อนจะหยิบมันขึ้นมาพลิกดู

ผมหวังว่าผมจะไม่ทำแบบนั้นเลย

เมื่อพลิกรูปถ่ายดู ความคิดของผมก็หยุดชะงัก ผมหยิบรูปอีกใบออกมาแล้วจ้องมองสลับไปมาระหว่างรูปทั้งสองด้วยความไม่อยากจะเชื่อ

นั่นมัน... ผมทำใจยอมรับสถานการณ์นี้ได้ยากเหลือเกิน

รูปถ่ายทั้งสองใบแสดงฉากเดียวกัน คู่รักยืนอยู่ข้างรถไฟ สวมเสื้อผ้าแบบเดียวกัน และโพสท่าด้วยสีหน้าแบบเดียวกัน พวกเขาดูเหมือนคู่รักที่สมบูรณ์แบบ แต่มีปัญหาเพียงอย่างเดียว ไม่สิ ปัญหาใหญ่สองอย่าง

*ยายแก่คนนั้น... เธอคือผู้หญิงคนเดียวกับในรูปแรก ข้อแตกต่างเพียงอย่างเดียวคือเธอแก่กว่าในรูปก่อน มีริ้วรอยปรากฏขึ้นใต้ตาและจมูกเล็กน้อย*

แต่มันไม่ใช่รูปลักษณ์ของเธอที่ทำให้ผมสติหลุด สิ่งที่ทำให้ผมสติหลุดจริงๆ คือผู้ชายคนนั้น

*เขา... แม้จะสวมสูทและหมวกทรงสูงแบบเดียวกัน แต่เขาเป็นคนละคนกันอย่างสิ้นเชิง ใช่ เมื่อมองดูรูปทั้งสองใบ มันชัดเจนสำหรับผมว่าทั้งคู่เป็นคนละคนกัน ตั้งแต่การที่เขาดูแก่กว่าผู้ชายในรูปก่อน สีตา ความยาวของเส้นผม และโครงหน้าโดยรวม พวกเขาไม่มีทางเป็นคนเดียวกันได้เลย*

และในตอนนั้นเองที่ผมก็นึกถึงคำพูดของยายแก่ขึ้นมาได้

*นั่นคือรูปที่ฉันถ่ายกับสามีคนแรกเมื่อนานมาแล้ว เขากำลังจะออกเดินทางไปทำงานไกลๆ พอดี*

*...น่าเสียดายจริงๆ ที่เขาไม่เคยกลับมาอีกเลยหลังจากการเดินทางครั้งนั้น*

ผมสูดลมหายใจเข้าลึกๆ พยายามอย่างเต็มที่เพื่อให้มีสติขณะเรียบเรียงเบาะแสและข้อมูลทั้งหมดที่รวบรวมมาได้จนถึงตอนนี้

*เมื่อดูจากที่เธอแก่ขึ้นในรูปนี้ และภาพลักษณ์ของคนในรูปดูเปลี่ยนไป ก็น่าจะสันนิษฐานได้ว่านี่คือสามีคนที่สองของเธอ? ใช่ ต้องเป็นอย่างนั้นแน่... แต่ทำไมเธอถึงตัดสินใจถ่ายรูปเลียนแบบรูปเดิมล่ะ? แล้วก็...*

ผมก้มลงมองศพที่อยู่ไม่ไกลจากตัวผมแล้วมองไปที่รูปถ่ายอีกครั้ง พยายามอย่างสุดความสามารถไม่ให้มือสั่น

*...นี่คือสามีคนที่สองของเธอเหรอ? ทำไมเขาถึงเป็นแบบนี้? เกิดอะไรขึ้น? เธอมีความเกี่ยวข้องอะไรกับชายบิดเบี้ยว? ทำไมเขาถึงมาอยู่ที่นี่...?*

มีคำถามมากมายอยู่ในหัวของผม แต่กลับมีคำตอบเพียงน้อยนิด ผมปวดหัวแค่เพียงคิดถึงสถานการณ์นี้ แต่ผมก็รู้ว่าผมเสียเวลาไปมากกว่านี้ไม่ได้แล้ว ผมก้าวเข้าไปใกล้หน้าต่างอีกนิด แอบมองออกไปเพื่อดูว่ายายแก่ยังอยู่ตรงนั้นไหม แต่...

“หืม?”

เธอหายไปแล้ว พื้นที่ข้างนอกที่เธอเคยยืนอยู่นั้นว่างเปล่า

*เดี๋ยวก่อน ถ้าเธอไม่อยู่ตรงนั้น แล้วเธอไปอ—*

*กริ๊ก!*

เสียงคลิกเบาๆ ดังสะท้อนไปทั่วห้อง ร่างกายของผมแข็งทื่อขณะที่ลูกบิดประตูข้างๆ ถูกบิดอย่างนุ่มนวล และร่างของหญิงชราก็ปรากฏตัวขึ้น

“อ๊ากกก—!”

ผมไม่ลังเลเลยแม้แต่นิดเดียว ผมพุ่งตัวไปที่ประตูแล้วกระแทกไหล่เข้ากับบานประตูในขณะที่มือของหญิงคนนั้นสอดเข้ามาติดอยู่ระหว่างซอกประตู เสียงกระดูกหักที่น่าสะอิดสะเอียนดังเข้าหูผมหลังจากนั้นไม่นาน ผมปล่อยประตูแล้วรีบวิ่งไปที่หน้าต่าง ก่อนจะใช้หมัดที่เคลือบด้วยสารสีดำต่อยมันโดยตรง

*ปัง!*

เมื่อมองย้อนกลับไป ประตูก็ถูกกระแทกเปิดออก และยายแก่ก็ปรากฏตัวขึ้นอีกครั้ง สายตาของเราสบกันเพียงชั่วครู่ก่อนที่ผมจะกระโดดลงจากชั้นสอง ขาของผมรับแรงกระแทกจากการตกอย่างเต็มที่ขณะที่ผมรีบวิ่งหนีไป

*วิ่ง ผมแค่ต้องวิ่ง...!*

ผมไม่หันกลับไปมองแม้แต่ครั้งเดียวขณะที่วิ่งหนีไป ผมแค่รู้ว่าผมต้องวิ่ง นั่นคือทั้งหมดที่ผมรู้ แค่วิ่งไปเท่านั้น
