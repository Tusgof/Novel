# ตอนที่ 68 - เด็กหญิงตัวน้อย [1]

*ฮึก... ฮึก...*

เสียงร้องไห้เบาๆ ลอยมาในอากาศขณะที่ผมจ้องมองไปที่ประตู ร่างกายแข็งทื่อไปหมด เงาสลัวสายหนึ่งลอดผ่านช่องประตูแคบๆ เข้ามา มันทอดยาวไปตามพื้นและยาวขึ้นเรื่อยๆ ตามแรงผลักประตูของร่างนั้น ผมหยุดหายใจ สายตาเหลือบมองสลับไปมาระหว่างหน้าต่างร้านค้าและประตู แต่แล้ว—

“หิวจัง... ใครก็ได้...”

เสียงของเด็กสาวดังขึ้นต่อ และประตูนั้นก็หยุดเคลื่อนไหว

“...หิวเหลือเกิน ได้โปรด...”

เสียงของเธอยังคงวนเวียนอยู่ในอากาศ ลอยมาจากภายในห้องอาหารและสถานที่ที่ผมอยู่ ผมไม่รู้แน่ชัดว่าที่ไหน แต่ผมรู้ว่าต้องขยับตัวแล้ว จะอยู่ที่นี่ต่อไปไม่ได้ ดังนั้นผมจึงเม้มริมฝีปากแน่นขณะจ้องมองไปยังประตูที่นำไปสู่ห้องอาหาร ผมถอดรองเท้าออกเพื่อเก็บเสียงฝีเท้าและเริ่มเคลื่อนที่ไปทางนั้นอย่างเงียบเชียบ ผมพยายามก้าวเท้าให้เบาที่สุดเท่าที่จะทำได้ก่อนจะไปหยุดอยู่ที่อีกด้านหนึ่งของประตู

*แค่นี้น่าจะพอ*

ผมกลั้นหายใจพลางกำเสื้อตัวเองไว้ ในขณะเดียวกันก็จ้องมองไปยังประตูข้างๆ

*...ถ้าประตูเปิดออก มันจะบังตัวผมพอดี แบบนี้น่าจะดีกว่า*

เมื่อก้มลงมอง สายตาของผมก็ปะทะกับเงาที่ยังคงทอดยาวอยู่บนพื้น ผมรู้ว่าร่างนั้นอยู่ข้างๆ ผมนี่เอง... ตรงอีกฟากหนึ่งของประตู

“ได้โปรด...”

*ฮึก ฮึก*

เสียงร้องไห้ยังคงดำเนินต่อไปและดังขึ้นกว่าเดิม ผมฟังเสียงสะอื้นของเธอพลางจับจ้องไปที่เงานั้น ผมตื่นตัวถึงขีดสุด ทั่วทั้งร่างเกร็งเครียดขณะพยายามผ่อนลมหายใจให้แผ่วเบาที่สุดเท่าที่จะทำได้ ผม... จะปล่อยให้มันรู้สึกถึงตัวตนของผมไม่ได้ โชคดีที่เสียงร้องไห้ดังขึ้นเรื่อยๆ ในทุกวินาทีที่ผ่านไป

“หิวจัง... ใครก็ได้...”

มันดังมาก และในไม่ช้าร่างเงาหลังประตูก็หันหลังกลับไป เงาบนพื้นหดเล็กลงเมื่อมันเริ่มเคลื่อนที่ห่างออกไป ภาพนั้นทำให้ผมรู้สึกเบาใจขึ้นเล็กน้อย อย่างไรก็ตาม ผมยังคงระวังตัวแจ รออยู่สองสามวินาทีก่อนจะหยิบโทรศัพท์ออกมาแล้วค่อยๆ เลื่อนมันไปที่ช่องว่างใต้ประตูอย่างช้าๆ ผมขยับมันอย่างระมัดระวังที่สุด ให้พอแค่ให้กล้องแอบมองลอดไปได้

*ใช่ แบบนี้น่าจะยังซ่อนพ้นอยู่ มันควรจะ—*

แต่ทันทีที่ผมเห็นหน้าจอ ลมหายใจก็ติดขัดอยู่ในลำคอ ใบหน้าทุกใบหน้าหันมาทางประตู จ้องตรงมายังช่องแคบๆ นั้น ราวกับกำลังเฝ้ารอ ผมรู้สึกขนลุกซ่านไปทั่วทุกส่วนของร่างกายขณะพยายามอย่างสุดความสามารถที่จะรักษาจังหวะหายใจให้คงที่ นั่น... พวกเขากำลังรอผมอยู่เหรอ? ผมกลืนน้ำลายอย่างประหม่าก่อนจะดึงโทรศัพท์กลับมา พยายามบังคับมือไม่ให้สั่น

*ถ้าเมื่อกี้ผมชะโงกหัวออกไปดูตรงๆ ผมคงถูกเห็นไปแล้วแน่ๆ...*

ความคิดนั้นทำให้ผมสั่นสะท้าน ถึงอย่างนั้น เมื่อนึกถึงพวกเขาและได้ยินเสียงร้องไห้ที่ยังคงแว่วอยู่ในอากาศ ผมก็เริ่มสงสัยว่าทำไมถึงไม่มีใครทำอะไรเลย พวกคนรับใช้ยังคงเดินไปมาอย่างไม่ใส่ใจ ในขณะที่คนในครอบครัวเอาแต่จ้องมองมาที่ประตู

*...นี่มันปัญหาใหญ่แล้ว*

ถ้าผมเดาไม่ผิด ผมต้องไปให้ถึงจุดที่เสียงร้องไห้ดังมา แต่การจะทำแบบนั้นได้ ผมต้องเข้าไปในห้องและเดินผ่านพวกคนรับใช้ไป แต่ผมจะทำแบบนั้นได้ยังไงกัน? ภารกิจนี้ดูเหมือนจะเป็นไปไม่ได้เลย

*ไม่ มันไม่ใช่ว่าเป็นไปไม่ได้ มันต้องมีสักทางสิ*

ผมเริ่มเค้นสมองคิดทบทวนเรื่องนี้

*ห้องที่เต็มไปด้วยคนรับใช้ คนสี่คนที่กำลังกินข้าวอยู่ที่โต๊ะอาหาร เด็กที่กำลังร้องไห้...*

ผมกัดริมฝีปากพลางครุ่นคิดถึงสถานการณ์ ในที่สุดใจของผมก็ไปหยุดอยู่ที่ไอเทมชิ้นหนึ่งที่ผมเคยเห็นในร้านค้า มันเป็นหนึ่งในไอเทมที่ผมเคยดูผ่านๆ และดูเหมือนจะเหมาะกับสถานการณ์ปัจจุบัน

─────[ร้านค้า]─────

**[คุณฮักส์ (Mr. Huggs)]** : ตุ๊กตาหมีสกปรกที่ช่วยลดความก้าวร้าวในรัศมี 5 เมตร อย่างไรก็ตาม การสัมผัสเป็นเวลานานจะทำให้เกิด *อาการเสพติดอย่างรุนแรง* และความไม่มั่นคงทางอารมณ์เมื่อต้องแยกจากกัน ราคา : 2,178 SP

─────[ร้านค้า]─────

“...อา”

ผมรู้สึกลังเลขณะจ้องมองไอเทมในร้านค้า มีความสงสัยมากมายผุดขึ้นในหัวขณะจ้องมองมัน ลดความก้าวร้าว... มันจะใช้ได้ผลนานแค่ไหน? นี่เป็นไอเทมระดับเริ่มต้น และพวกสัตว์ประหลาดข้างในก็น่าจะแข็งแกร่งกว่านั้นมาก มันจะยับยั้งความก้าวร้าวของพวกมันได้นานแค่ไหน? มันจะใช้กับพวกมันได้ผลจริงเหรอ? ความสงสัยถาโถมเข้ามาในหัวขณะที่ผมจ้องมองรูปตุ๊กตาหมีข้างคำอธิบายไอเทม ด้วยแต้ม 10,450 SP ที่มีอยู่ ผมสามารถซื้อมันได้อย่างสบายๆ ปัญหาก็คือมันจะใช้ได้ผลหรือไม่ ถ้ามันไม่ได้ผล ผมจะทำยังไง?

*แล้วผมมีทางเลือกอื่นอีกเหรอ? ไม่สิ มันอาจจะมีประโยชน์ในภายหลังก็ได้ ต้องซื้อแล้วล่ะ*

ผมกวาดสายตาดูไอเทมอื่นๆ ที่มีให้เลือก และมีอีกชิ้นหนึ่งที่สะดุดตาผม

─────[ร้านค้า]─────

**[Quickstitch Outfit]** : ชุดเสื้อผ้าเวทมนตร์ที่สามารถเปลี่ยนเป็นชุดใดก็ได้ตามที่ผู้สวมใส่จินตนาการทันที แม้จะให้สไตล์และความสบายที่สมบูรณ์แบบ แต่การใช้งานมากเกินไปอาจนำไปสู่การสูญเสียตัวตน เนื่องจากผู้สวมใส่จะเริ่มลืมรูปลักษณ์ดั้งเดิมของตนเอง ราคา: 3,450 SP

─────[ร้านค้า]─────

มันเป็นไอเทมที่ก่อนหน้านี้ผมมองข้ามไปว่าไร้ประโยชน์ แต่เมื่อนึกถึงสถานการณ์ปัจจุบัน ไอเทมชิ้นนี้แหละที่อาจจะเปลี่ยนสถานการณ์ให้ผมได้

*เจ้านี่ รวมกับตุ๊กตาหมี ผมอาจจะ... ปลอมตัวเป็นหนึ่งในคนรับใช้ได้*

ปัญหาก็คือมันเป็นคำว่า 'อาจจะ' ที่เสี่ยงมาก ผมไม่แน่ใจเลยว่าจะหลอกพวกมันได้ไหม มีดเป็นของที่มีประโยชน์ชิ้นถัดไปสำหรับสถานการณ์นี้ แต่ผมสงสัยว่าตัวเองจะทำอะไรพวกคนรับใช้ได้แค่ไหนกัน ถ้าผมเดาไม่ผิด พวกมันแข็งแกร่งกว่าผมมาก สถานการณ์ตอนนี้ทำให้การต่อสู้เป็นเรื่องที่เป็นไปไม่ได้เลย ถ้าอย่างนั้น...

*สงสัยนี่จะเป็นทางเลือกเดียวของผมแล้ว*

ผมไม่ลังเลอีกต่อไปและกดซื้อไอเทมทั้งสองชิ้นทันที

*ปุ้ง*

ตุ๊กตาหมีและเสื้อเชิ้ตสีขาวเรียบๆ ตกลงมาจากด้านบนขณะที่ผมยื่นมือไปรับไว้ ยอดคงเหลือลดลงจาก 10,450 เหลือ 4,822 ผมรู้สึกเสียดายแต้มอยู่บ้าง แต่ก็พยายามเพิกเฉยต่อความรู้สึกนั้นขณะจ้องมองไอเทมสองชิ้นในมือ ในที่สุดผมก็สวมเสื้อเชิ้ตตัวนั้นในขณะที่ถือตุ๊กตาหมีไว้

*มันใช้งานยังไงนะ?*

ครู่หนึ่งหลังจากสวมเสื้อ ผมลองดึงมันดูเพื่อดูว่ามีการเปลี่ยนแปลงอะไรไหม แต่มันก็ยังเป็นแค่เสื้อเชิ้ตสีขาวธรรมดา นั่นคือตอนที่ผมกลับไปอ่านคำอธิบายอีกครั้งแล้วตบหน้าตัวเองเบาๆ

“จริงด้วย...”

ผมหลับตาลงและจินตนาการถึงเสื้อผ้าที่พวกคนรับใช้สวมใส่ เสื้อสูทสีดำทับเสื้อเชิ้ตสีขาวสะอาดตาที่สอดชายเสื้อไว้ในกางเกงสแล็คสีดำไร้รอยยับอย่างเรียบร้อย ทันทีที่ภาพนั้นก่อตัวขึ้นในใจ บางอย่างก็เปลี่ยนไป และเมื่อผมลืมตาขึ้นอีกครั้ง เสื้อผ้าของผมก็เปลี่ยนไปแล้ว

*...ได้ผลแฮะ*

ผมก้มลงมองเสื้อสูทและเสื้อเชิ้ต ซึ่งเหมือนกับเครื่องแบบของคนรับใช้ทุกรายละเอียด จากนั้น... ผมกอดตุ๊กตาหมีไว้แน่น สูดลมหายใจเข้าลึกๆ ก่อนจะหันความสนใจไปที่ประตู

*ขอให้ได้ผลทีเถอะ...*

ผมค่อยๆ ยื่นมือออกไป กดลงบนลูกบิดก่อนจะดึงมันออก

*เอี๊ยดดด...*

แสงสว่างสาดส่องเข้ามาในทางเดิน และผมก็ก้าวเข้าไปในห้องอาหาร
