# ตอนที่ 172 - ภารกิจใหม่ [1]

“ฮวาอ้าม...” ผมค่อยๆ ลืมตาขึ้นช้าๆ ก่อนจะพยุงตัวลุกนั่ง มือข้างหนึ่งคลึงท้ายทอย ส่วนอีกข้างยกขึ้นบังแสงที่ส่องทะลุหน้าต่างเข้ามา

“อึก...นี่กี่โมงแล้วเนี่ย?”

ผมคลำหาโทรศัพท์บนเตียงอยู่นานกว่าจะเจอ แล้วรีบยกขึ้นมาดูเวลา

“บ่ายสอง?”

ตาผมเบิกกว้างทันที

“เชี่ยเอ๊ย! ผมนอนไปนานแค่ไหนกัน?”

สิ่งสุดท้ายที่ผมจำได้คือกลับหอหลังจากรีบปล่อยเกม แล้วก็ฟุบหลับทันทีที่ถึงเตียง ถึงจะจำได้ว่าตอนนั้นดึกมากแล้ว แต่ผมก็รู้ว่ามันไม่ได้ดึกขนาดนั้น อย่างมากก็แค่ตีห้า

แล้วผมไปนอนนานขนาดนี้ได้ยังไงกันวะ?

ถ้าผมเผลอหลับไปตอนเจ็ดโมงเช้าจริงๆ แล้วตอนนี้เป็นบ่ายสอง งั้นก็...

“ผมนอนตั้งเจ็ดชั่วโมงเลยเหรอ?!”

มันจะบ้าหรือไง! แนวคิดจากต่างดาวอะไรเนี่ย?!

“ไม่ๆๆ ผมเสียเวลาไปกับการนอนมากเกินไปแล้ว”

ผมกระโดดลงจากเตียง พุ่งเข้าห้องน้ำ อาบน้ำอย่างลวกๆ เปลี่ยนเสื้อผ้า แล้วรีบวิ่งกลับไปที่ออฟฟิศทันที

ยังมีเรื่องที่ผมต้องทำอีกตั้งเยอะ ผมมัวมานอนกินบ้านกินเมืองแบบนี้ไม่ได้หรอก ชิบหายเอ๊ย จะให้จู่ๆ ไปจ้างทีมมาช่วยทำระบบมัลติเพลเยอร์ก็ไม่ได้ซะหน่อย อ้อ จริงสิ ผมจำได้ว่าส่งลิงก์ให้เจมี่ คาร์เตอร์ไปแล้วด้วย ไม่รู้ยอดขายเกมเป็นยังไงบ้าง...

ความคิดสารพัดแล่นพล่านอยู่ในหัว ขณะที่ผมพุ่งเข้าไปในกิลด์ แล้วตรงไปที่ลิฟต์ซึ่งพาผมลงไปยังแผนกที่คุ้นเคยอย่างรวดเร็ว

เมื่อก่อนสถานที่แห่งนี้ทำให้ผมอึดอัดจนแทบหายใจไม่ออก แต่ตอนนี้ทุกอย่างกลับต่างออกไป ที่นี่ให้ความรู้สึกเหมือนบ้านยิ่งกว่าหอตัวเองเสียอีก

แล้วในตอนที่ผมเดินผ่านพื้นที่ทำงานหลักไป จนในที่สุดมองเห็นออฟฟิศของตัวเอง มือข้างหนึ่งก็ยื่นมาคว้าไหล่ผมไว้กะทันหัน

“เดี๋ยวก่อน”

“หืม? ไคล์?” ผมหยุดแล้วหันกลับไปมองเขา “อรุณสวัสดิ์...?”

“นี่มันบ่ายแล้ว”

“อ้อ ก็เหมือนกันนั่นแหละ”

ตราบใดที่ยังมีแสง สำหรับผมก็คือตอนเช้า

“นั่นมัน...” ไคล์ทำท่าเหมือนอยากพูดอะไรต่อ แต่สุดท้ายก็แค่ส่ายหน้า “ช่างเถอะ มีเรื่องที่ฉันอยากคุยกับนาย”

“อะไร?” เห็นสีหน้าเขาค่อนข้างจริงจัง ผมจึงพยักหน้าแล้วชี้ไปทางออฟฟิศตัวเอง “ก็ดีเหมือนกัน เพราะผมเองก็มีเรื่องอยากคุยอยู่สองสามอย่าง”

หลักๆ ก็คือวิธีเข้าไปในตลาดมืด เรื่องนี้ผมอยากรู้แทบตายมาสักพักแล้ว

“นายก็มีเรื่องจะคุยด้วยเหรอ? หืม...เดี๋ยวก่อน ฉันว่าฉันรู้ว่านายต้องการอะไร”

“นายรู้เหรอ?” ผมหันไปมองไคล์อย่างแปลกใจ แต่เขาไม่ได้พูดอะไรต่อ แค่เดินมุ่งหน้าไปยังออฟฟิศของผม

ผมเดินตามไปติดๆ พอถึงหน้าประตู ผมก็เปิดมัน พาเขาเข้าไปข้างใน แล้วปิดประตูตามหลัง

“เอาล่ะ”

เมื่อแน่ใจแล้วว่าไม่มีหูตาคนอื่น ไคล์ก็หันมาทางผมพร้อมยื่นถุงเล็กๆ ใบหนึ่งให้

“นี่คือ?”

“เศษชิ้นส่วนที่นายชนะพนันมาไง”

“โอ๊ะ!”

ดวงตาผมเป็นประกายขึ้นมาทันที

ใช่สิ! เกือบลืมไปแล้ว!

ผมคว้าถุงมาอย่างตื่นเต้น รีบเปิดดูแล้วนับทีละชิ้นเพื่อให้แน่ใจว่าไม่มีอะไรหายไป พอมั่นใจว่าครบทั้งหมด ผมก็อดยิ้มกว้างไม่ได้

“ดูนายมีความสุขมากนะ?”

“มีความสุข?” แน่นอนว่าผมมีความสุข ด้วยสิ่งนี้ ผมก็ขยับเข้าใกล้ลำดับที่สามไปอีกขั้นแล้ว

“ถึงฉันจะไม่อยากเป็นคนส่งข่าวร้าย แต่เศษชิ้นส่วนที่นายถืออยู่นี่ล้วนมีความบริสุทธิ์ต่ำมาก ถึงจะขายได้เงินดีอยู่ แต่เอาไปใช้ไม่ได้”

พอพูดมาถึงตรงนั้น สีหน้าของเขาก็เคร่งขรึมขึ้น เคร่งขรึมจนชั่วขณะหนึ่งผมรู้สึกเหมือนหัวใจกระตุกวูบ

“ที่ฉันบอกว่าใช้ไม่ได้ หมายถึงห้ามเอาไปคิดหรือพิจารณาใช้ปลุกพลังเด็ดขาด ถ้าทำแบบนั้น ผลที่ตามมาจะเลวร้ายมาก อาจเกิดรอยร้าวหลายจุด หรือแย่ยิ่งกว่านั้น...อาจก่อให้เกิดเศษเสี้ยวปัญญาได้”

น้ำเสียงของไคล์ยิ่งจริงจังขึ้นอีก

“ฉันพูดอีกครั้ง อย่าแม้แต่จะคิดกลืนกินเศษชิ้นส่วนพวกนี้ ถ้านายยังไม่อยากตาย เข้าใจไหม?”

“...ครับ”

พูดตามตรง คำเตือนจริงจังแบบพ่อแม่ของไคล์นี่ชวนให้ผมขำอยู่เหมือนกัน แต่ผมรู้ดีว่าคำพูดของเขามาจากความเป็นห่วง เพราะงั้นผมเลยพยักหน้ารับไปตามธรรมชาติ

ยังไงผมก็ไม่ได้คิดจะใช้พวกมันในสภาพนั้นอยู่แล้ว

“ก็ดี”

หลังจากได้รับคำยืนยันจากผม ไคล์ก็ดูโล่งใจขึ้นเล็กน้อย ก่อนจะหยิบแฟ้มออกมาแล้ววางแปะลงบนโต๊ะ

แปะ!

“หืม? นี่คือ...?” ผมมองแฟ้มอย่างสงสัย เปิดมันออก แล้วเริ่มอ่านผ่านๆ ช้าๆ

ข้างในมีข้อความอยู่มากมาย และผมก็ไล่อ่านข้ามไปอย่างรวดเร็ว สุดท้ายเรื่องพวกนี้ก็ไม่ได้เกี่ยวกับผมโดยตรงอยู่ดี

แต่สิ่งที่ดึงความสนใจของผมกลับเป็นภาพวาดหลายภาพ

แต่ละภาพดูเหมือนภาพร่างลวกๆ ที่ไม่ได้ใส่ใจอะไร คล้ายสิ่งที่เด็กคนหนึ่งขีดเขียนขึ้นมา ชายคนหนึ่งแต่งหน้าเป็นตัวตลก สวมเสื้อผ้าสีฉูดฉาดที่ไม่เข้ากัน จมูกแดงใหญ่เกินจริง หยิกผมแดงยุ่งเหยิง และถือลูกโป่งสีแดงติดตัวอยู่ตลอดเวลา

แต่สิ่งที่เด่นที่สุดกลับเป็นดวงตา

หลุมดำลึกมืดสนิท ถูกขีดวนทับด้วยเส้นหมุนหนักๆ ทีละชั้น ยิ่งวนก็ยิ่งหนาแน่น ราวกับว่าคนวาดหมกมุ่นจนเกือบเสียสติ เพียงเพื่อจะวาดมันให้ออกมาถูกต้อง

อะไรของ...

“นี่คือคดีล่าสุดที่หัวหน้าแผนกมอบหมายให้ฉัน มันเกี่ยวข้องกับความผิดปกติล่าสุดที่เพิ่งถูกค้นพบ พวกเขาเรียกมันว่า ‘ตัวตลกที่ซ่อนตัว’ จนถึงตอนนี้ยังไม่มีใครเคยเห็นความผิดปกตินั้นกับตาตัวเอง และก็แทบไม่มีข้อมูลอะไรเกี่ยวกับมันเลย เราไม่รู้แม้แต่ระดับหรือกฎของมัน เหตุผลเดียวที่เรารู้ว่ามันมีอยู่ ก็เพราะภาพวาดในแฟ้มนี้”

“...อ้อ” ผมวางแฟ้มลง

แค่ฟังก็รู้แล้วว่าเรื่องนี้กลิ่นไม่ดี เราอยู่ห่างๆ จากมันให้มากที่สุดจะดีกว่า...

“เด็กที่วาดภาพพวกนี้ เป็นเด็กจากสถานเลี้ยงเด็กกำพร้าแห่งหนึ่ง สถานที่ที่ชื่อว่า Happy Kids Orphanage”

ความคิดในหัวผมหยุดนิ่งทันทีที่ได้ยินคำพูดของไคล์ และเมื่อผมหันหน้าไปช้าๆ ก็เห็นเขาพยักหน้าช้าๆ เช่นกัน

“ใช่ ที่เดียวกับสถานเลี้ยงเด็กกำพร้าที่พวกเราสองคนโตมา”

ทันทีที่เขายืนยัน หัวใจของผมก็ค่อยๆ จมดิ่งลงไป ขณะที่เปลือกตาปิดลงช้าๆ

“...เชี่ยเอ๊ย”

มีตั้งหลายที่ ดันต้องเป็นที่นั่น

“หัวหน้าแผนกบอกว่าฉันสามารถตั้งทีมเพื่อไปที่นั่นได้ ปกติฉันคงไม่พานายไปด้วยหรอก แต่จากที่เห็นผลงานของนายก่อนหน้านี้ ฉันเลยคิดว่า...บางทีนายอาจสนใจ และก็...” ไคล์หยุดไป สีหน้าดูซับซ้อนขึ้นเล็กน้อย

“...แม่ผู้ดูแลอยากพบนาย เธอบอกว่าถึงเวลาที่นายควรกลับไปเยี่ยมแล้ว พวกนายสองคนมีหลายเรื่องที่จำเป็นต้องคุยกัน”

ไม่เลย ไม่มีอะไรให้คุยทั้งนั้น ในบรรดาทุกคน เธอคือคนสุดท้ายที่ผมอยากคุยด้วย เธอยังเป็นเหตุผลหลักที่ทำให้ผมแทบไม่เคยกลับไปที่นั่นด้วย

แต่ถึงอย่างนั้น...

“โอเค ผมไป”

สุดท้ายผมก็พยักหน้ารับเงียบๆ ไม่ใช่เพราะเธอ แต่เพราะเด็กๆ ต่างหาก พวกเขาทุกคนไม่ทางใดก็ทางหนึ่งก็เป็นเหมือนพี่น้องของผม

และที่สำคัญที่สุด...

บางทีถ้าผมไปที่นั่น ผมอาจหาเบาะแสเกี่ยวกับตัวเองก่อนที่โลกจะเปลี่ยนไปได้

บางที บางทีจริงๆ...

ผมอาจเจออะไรที่มีประโยชน์ก็ได้
