# ตอนที่ 27 - เสียงกรีดร้อง

“เอาละ ฉันควรจะจัดการกับมันยังไงดี?”

สิ่งแรกที่ฉันกังวลเกี่ยวกับเพลงประกอบคือความรุนแรงของมัน—มันแรงเกินไป ถ้าเปิดตามที่เป็น ฉันกลัวว่าจะไปกระตุ้นให้เกิดความโกลาหลขึ้นมา

“ฉันอาจทำให้คนตายได้เลยนะเนี่ย”

ยิ่งไปกว่านั้น ฉันต้องแน่ใจว่ามันไม่ส่งผลกระทบมากพอจนคนในกิลด์สังเกตเห็น โชคดีที่ฉันคิดทางออกไว้ล่วงหน้า และหลังจากทดสอบหลายครั้ง ก็มั่นใจว่ามาถูกทางแล้ว ขณะเอนหลังพิงเก้าอี้

“เฮ้อ... ขอบคุณพระเจ้าที่มันใช้ได้”

จุดสำคัญคือความชัดเจนของเสียงดนตรี ยิ่งชัดเจนมากเท่าไหร่ ผลกระทบก็ยิ่งรุนแรง

“ในกรณีนี้ ถ้าฉันหาอัตราส่วนที่สมบูรณ์แบบเจอ ก็น่าจะรักษาสมดุลได้—ให้มันทรงพลังพอใช้ได้ผล แต่แนบเนียนจนแทบไม่กระทบคนที่กำลังเล่นเกม”

*นั่นคือทั้งหมดที่ต้องการ เป้าหมายไม่ใช่ให้ผู้เล่นฉีกหน้าตัวเอง—แต่คือการกล่อมพวกเขาให้เคลิ้มพอประมาณ ลดการป้องกันลง ให้จังหวะ Jump Scare กระแทกเข้าเต็มแรง ถ้ามันได้ผล ฉันมั่นใจว่ามันจะทำให้แม้แต่คนที่คุ้นเคยกับสถานการณ์น่ากลัวยังต้องขวัญผวา*

เมื่อคิดถึงเรื่องนี้ ฉันจึงไล่ดูรายการเพลงปลอดลิขสิทธิ์ยาวเหยียด แล้วผสมผสานเพลงประกอบต้นฉบับกับซาวด์มิกซ์ที่หามาให้เข้ากับธีมโดยรวม บทเพลงของวาทยกรไม่ได้เข้ากับตัวเกมนัก มันมีความคลาสสิกเกินไป เลยไม่ค่อยกลมกลืนกับสิ่งที่ฉันพัฒนาขึ้น ฉันเลยตัดสินใจผสมมันเข้ากับเพลงประกอบที่... รุนแรงกว่าเดิม

“หืม”

แต่ขณะกำลังปรับเปลี่ยน ฉันก็หยุดชะงักและจ้องคอมพิวเตอร์ตรงหน้า พัดลมส่งเสียงครางกระหึ่ม ความร้อนจากโปรเซสเซอร์สัมผัสถึงแขน

“ทั้งที่เปลี่ยนแล้ว แต่ก็ยังรู้สึกขาดอะไรบางอย่าง”

เดิมทีเกมนี้ไม่ได้ถูกสร้างมาให้เล่นพร้อมดนตรี ทำให้มันไม่ค่อยเข้ากับการออกแบบในปัจจุบัน แถมยังเปิดเพลงนานเกินไปไม่ได้ เพราะกลัวไปกระตุ้นอะไรบางอย่าง สิ่งนี้ทำให้พัฒนายากขึ้นเล็กน้อย

ในที่สุด ฉันก็นั่งเงียบๆ จ้องคอมพิวเตอร์ก่อนครางออกมา

“…ฉันต้องเปลี่ยนกลไกเกมสินะ?”

ถอนหายใจกับตัวเองแล้วเช็กเวลา ตอนนี้ประมาณตีสองครึ่ง เปลือกตาหนักอึ้งขึ้นทุกวินาที คลื่นความง่วงโถมเข้าใส่ ฉันไม่ได้นอนมาเกิน 24 ชั่วโมงแล้ว ร่างกายเริ่มประท้วง ต้องไปนอนสักหน่อย แต่ถึงอย่างนั้น…

“ไว้ค่อยนอนทีหลังแล้วกัน”

ฉันยังคงจดจ่อกับเกม ปรับแต่งแก้ไขต่อเนื่อง กว่าจะรู้ตัวก็ผ่านไปอีกหลายชั่วโมง เมื่อจัดการเก็บรายละเอียดสุดท้ายของโครงสร้างเกมเสร็จ ความเหนื่อยล้าก็ถึงขีดสุด แต่ก่อนจะเผลอหลับ ฉันก็ย้ายไฟล์สำเนาลงแฟลชไดรฟ์ USB ได้สำเร็จ แล้วเดินออกไปล็อคประตูตามหลัง

*หาววว*

เมื่อก้าวออกจากพื้นที่สำนักงาน ก็หาวฟอดใหญ่ เปลือกตาหนักจนแทบเปิดไม่ขึ้น ข้างนอกยังมืดอยู่ แต่เริ่มเห็นคนทยอยเข้ามา พวกเขาดูเหมือนคนแฮงค์เหล้า คงมาจากงานเลี้ยงฉลองเด็กใหม่เมื่อคืน นั่นคือสาเหตุที่เมื่อคืนเงียบเหงา

โดยไม่คิดมาก ฉันมุ่งหน้าไปลิฟต์เพื่อกลับห้อง ต้องการนอนจริงๆ เสียดายที่เหนื่อยเกินไป ไม่อย่างนั้นคงสังเกตเห็นแล้วว่า USB ที่พกมาหลุดจากกระเป๋าไป กว่าจะรู้ตัวก็สายเกินไปแล้ว

7 โมงเช้า ปกติแล้วเป็นเวลาเริ่มงานของกิลด์สำหรับผู้ที่อยู่ในภาคส่วนกักกัน มันก็เหมือนงานออฟฟิศทั่วไป

“…อือออ เหนื่อยชะมัด”

“บอกฉันทีเถอะ เมื่อคืนแทบไม่ได้นอน นั่งดื่มกับพวกพี่ๆ ทั้งคืน”

“แค่คิดถึงรุ่นพี่โซอี้ที่ดื่มหนักขนาดนั้นแต่ไม่เมาเลย ยังขนลุกอยู่เลยเนี่ย”

“ถ้าเรื่องนั้น ฉันชอบรุ่นพี่ไคล์มากกว่าเยอะ เขาดูใจดีกว่าตั้งเยอะ…”

พนักงานใหม่มาถึงเป็นกลุ่มแรกในพื้นที่ของเจ้าหน้าที่ภาคสนาม ดวงตาหนักอึ้งด้วยความเหนื่อยล้า เสื้อผ้ายับยู่ยี่เล็กน้อย ในฐานะเด็กใหม่ พวกเขาไม่มีทางเลือกอื่นนอกจากต้องมาถึงก่อน มันเป็นมารยาทที่ต้องยึดถือ ถ้าไม่ถูกบังคับให้ดื่มทั้งคืน พวกเขาคงอยู่ในอารมณ์ที่ดีกว่านี้มาก

หลังจากวางกระเป๋า พนักงานใหม่ก็มุ่งหน้าไปห้องครัวที่ซ่อนตรงมุมห้อง แล้วเริ่มชงกาแฟสำเร็จรูป นี่คือสิ่งที่ดีที่สุดที่ที่นี่มีให้

“สงสัยจังว่าวันนี้จะให้เราทำอะไร”

ลอว์เรนซ์ หนึ่งในเด็กใหม่พูดขณะรินน้ำร้อนลงแก้ว

“…ฉันหวังว่าวันนี้คงไม่ต้องเข้าไปในเกตนะ ฉันไม่คิดว่าตัวเองจะมีสติพอเอาชีวิตรอด”

“วันนี้น่าจะรอดนะ เราคงถูกบังคับให้ทำเอกสารกับงานวิจัยมากกว่า ฉันเห็นทีมสอดแนมออกไปข้างนอกด้วย คิดว่าวันนี้ปลอดภัย”

“ดีเลย”

ลอว์เรนซ์ถอนหายใจโล่งอกขณะจิบกาแฟ

*ขึ…*

ใบหน้าบิดเบี้ยวทันทีที่พยายามจิบ รีบดึงออกจากปาก

“อา ร้อน…”

เขาพึมพำเบาๆ สบถใส่กาแฟในใจ กำลังจะพูดอะไรต่อ แต่หางตาเหลือบไปเห็นแท่งดำๆ บนพื้น

“นั่นอะไรน่ะ?”

ด้วยความอยากรู้ เขาเดินเข้าไปหยิบขึ้นมา

“แฟลชไดรฟ์ USB เหรอ?”

“…หืม? ยังมีคนใช้ของพวกนี้อยู่อีกเหรอ?”

“ก็น่าจะนะ…”

ลอว์เรนซ์พลิก USB หาชื่อเจ้าของ แต่ไม่เห็นอะไร เขาขมวดคิ้ว หลังจากคิดอยู่ครู่หนึ่ง ก็เดินไปที่โต๊ะเปิดแล็ปท็อป โดยมีพนักงานใหม่อีกสามคนเดินตาม

“นายจะเช็กเหรอว่าเป็นของใคร?”

“…อืม มันอาจมีของสำคัญอยู่”

อาจเป็นของรุ่นพี่ระดับสูงก็ได้ คืนให้เร็วจะดีกว่า—ใครจะรู้ อาจเป็นตั๋วเบิกทางให้เข้าตาพวกพี่ๆ ก็ได้

ลอว์เรนซ์ไม่รอช้า ทันทีที่คอมพิวเตอร์เปิด ก็เสียบ USB เข้าไป

ไฟล์ชื่อ: **[Seth's USB stick]** ปรากฏขึ้นหลังไม่นาน

“เซธ?”

กลุ่มพนักงานใหม่กะพริบตาสับสน

“มีรุ่นพี่ชื่อเซธในแผนกด้วยเหรอ?”

“เซธ? ฉันไม่คิดว่ามีนะ…”

“ไม่มีหรอก”

ลอว์เรนซ์พูด สีหน้าผิดหวังขณะเปิดโฟลเดอร์ดูไฟล์เดียวที่อยู่ข้างใน

**[Game.Dem]**

“อ่า เขาเองเหรอ…”

ลอว์เรนซ์เอนหลังพิงเก้าอี้ ความผิดหวังปรากฏชัดบนใบหน้า ไม่ใช่แค่เขาเท่านั้น พนักงานใหม่คนอื่นก็เข้าใจทันทีว่าใครเป็นเจ้าของ USB

“มันคือ USB ของไอ้คนดวงดีนั่นแหละ”

“…ใช่”

ชื่อเสียงของเซธในหมู่พนักงานใหม่ไม่ค่อยดีนัก ทุกคนได้ยินข้อเสนอที่หัวหน้าแผนกมอบให้เขา มันเป็นข้อเสนอที่หลายคนใฝ่ฝัน การที่เขาได้รับข้อเสนอแบบนั้นจากการทดสอบครั้งเดียว—ซึ่งดูเหมือนเขาจะแก้ปัญหาได้เพราะโชคช่วยล้วนๆ—ทำให้หลายคนไม่พอใจ มีทั้งความอิจฉาริษยา แต่ก็มีความขุ่นเคืองที่สมเหตุสมผลปนอยู่ เพราะพวกเขาต้องทุ่มเทเวลาหลายชั่วโมงเพื่อแย่งชิงที่นั่งในกิลด์ การที่เขาได้รับตำแหน่งสูงกว่าโดยไม่ต้องพยายาม เหมือนตบหน้าพวกเขาชัดๆ

“ช่างเถอะ”

ลอว์เรนซ์ก็รู้สึกแบบเดียวกัน เขาไม่ได้มีความปรารถนาดีต่อเซธนัก ขณะกำลังจะดึง USB ออก ใบหน้าหนึ่งก็โผล่จากด้านหลัง

“โอ้? พวกนายกำลังเช็กอะไรกันอยู่เหรอ?”

ทันใดนั้น พนักงานใหม่ทุกคนก็ตื่นตัว

“รุ่นพี่!”

“…รุ่นพี่!”

“ใจเย็นๆ พวกนายต้องผ่อนคลายหน่อย”

เทอร์แรนซ์ยกมือให้พวกเขาใจเย็นลง เขาเพิ่งก้าวเข้ามาในออฟฟิศ สังเกตเห็นพนักงานใหม่รวมกลุ่มกัน ด้วยความสนใจ จึงเดินเข้ามาดู

ลอว์เรนซ์ยืดหลังตรง ดึง USB ออกแล้วปิดแล็ปท็อป

“ไม่มีอะไรครับ เราแค่เจอ USB ที่ตกอยู่ จะหาว่ามันเป็นของใคร”

“อ้อ แล้วเป็นของใครล่ะ?”

“…ของคนสังเกตการณ์ที่รุ่นพี่ไคล์พามาครับ ในนั้นมีตัวเดโมเกมที่เขากำลังทำอยู่”

“หืม?”

ทันใดนั้น แววตาแห่งความสนใจวาบขึ้นบนใบหน้าเทอร์แรนซ์ขณะมองไปที่ USB ไม่นาน รอยยิ้มก็ปรากฏ

“ฟังดูน่าสนใจดีนี่”

สายตาตกลงบนแล็ปท็อปของลอว์เรนซ์

“ลองเล่นดูหน่อยสิ”

“เอ๊ะ?”

ลอว์เรนซ์กะพริบตา แต่ก่อนจะได้พูดอะไร เทอร์แรนซ์ก็พูดต่อ

“…เสียบ USB เข้าไปสิ ลองเล่นตัวเดโมดู ฉันอยากรู้เหมือนกันว่าเกมมันน่ากลัวขนาดไหน”
