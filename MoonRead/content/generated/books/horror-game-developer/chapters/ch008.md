# ตอนที่ 8 - ภารกิจสำเร็จ

[โหลดเสร็จสิ้น!] เมื่อการแจ้งเตือนอีกข้อความกะพริบขึ้นมา โลกมืดรอบตัวผมก็จางหายไป และผมพบว่าตัวเองกลับมาอยู่ในพื้นที่สำนักงานอีกครั้ง “...ฉันกลับมาแล้วเหรอ?” ผมมองไปรอบๆ ทุกอย่างยังคงเหมือนเดิมก่อนที่ผมจะจากไป ชั่วขณะหนึ่งผมเกือบคิดว่าทุกอย่างเป็นเพียงความฝัน สิ่งที่ผมเผชิญมาเป็นเพียงภาพหลอนจากความเหนื่อยล้า แต่ความคิดนั้นก็หายไปอย่างรวดเร็วเมื่อหน้าจอตรงหน้ากะพริบขึ้นมา [ทำการเปลี่ยนแปลงเรียบร้อยแล้ว คุณจะได้รับรางวัลสำหรับการทำภารกิจสำเร็จในขณะนี้] *ปุ้ง!* ไอเทมชิ้นหนึ่งปรากฏขึ้นบนตักของผม “นี่มัน...?” ผมมองดูไอเทมชิ้นนั้นด้วยความตกใจเมื่อเห็นว่ามันคือหน้ากากจากก่อนหน้านี้ “เดี๋ยวนะ นี่คือรางวัลเหรอ?

ได้ยังไง—” คำพูดของผมถูกขัดจังหวะด้วยการแจ้งเตือนอีกครั้ง ───── [รางวัลที่ 1 : หน้ากากว่างเปล่า] ประเภท/ไอเทม *หน้ากากเรียบง่ายที่ใช้ปกปิดตัวตนของคุณ มีหลายสไตล์ที่ให้คุณลองใช้ได้* : ไม่ใช่ของใช้สิ้นเปลือง [รางวัลที่ 2 : แว่นตาภูตผี] ประเภท/ไอเทม แว่นตาที่จะช่วยให้ผู้สวมมองเห็นสิ่งที่คนอื่นมองไม่เห็น : ไม่ใช่ของใช้สิ้นเปลือง [รางวัลที่ 3 : ภาชนะกักกัน] ประเภท/โหนดพื้นฐาน เมื่อเปิดใช้งานโหนด ผู้ใช้จะได้รับความสามารถในการกักกันสิ่งมีชีวิตและวัตถุที่ผิดปกติ คำเตือน: หากความแข็งแกร่งของสิ่งผิดปกติเกินขีดจำกัดของโหนด การกักกันจะล้มเหลว ซึ่งอาจส่งผลให้เกิดการตีกลับอย่างรุนแรง” : ไม่ใช่ของใช้สิ้นเปลือง ───── “หือ” ไอเทมอีกชิ้นปรากฏขึ้น—มันคือแว่นตากรอบดำ “นี่คือ...?” ผมหันความสนใจไปที่รางวัลที่สอง แว่นตาภูตผีเหรอ?

*'ช่วยให้ผู้สวมมองเห็นสิ่งที่คนอื่นมองไม่เห็น?'* ผมจ้องมองแว่นตาอยู่สองสามวินาทีก่อนจะเปลี่ยนความสนใจไปยังรางวัลถัดไป โดยเฉพาะสายตาของผมตกลงไปที่คำอธิบาย “โหนดพื้นฐาน...?” มันคืออะไรกันแน่?

รางวัลที่สามนั้นแตกต่างจากสองอย่างแรก มันไม่ใช่ไอเทมเหมือนอย่างอื่น ผมไม่มีความรู้เลยว่ามันคืออะไรหรือใช้งานยังไง “สับสนชะมัด” ผมเกาข้างหัวพลางจ้องมองหน้ากากและแว่นตาในมือ หลังจากลังเลอยู่ครู่หนึ่ง ผมก็สวมแว่นตาเข้าไป หัวใจของผมเต้นรัวขณะที่จัดมันให้เข้าที่บนใบหน้า ผมรู้สึกถึงความหวาดกลัวที่น่าขนลุกผุดขึ้นมาจากภายใน *'คงไม่ได้เห็นผีหรอกใช่ไหม?'* “อ๊ะ....!” ทันทีที่ผมสวมแว่นตาลงบนใบหน้า ทัศนวิสัยของผมก็กลายเป็นสีน้ำเงิน “หนาว” อุณหภูมิลดฮวบลงในพริบตา ผมมองเห็นลมหายใจของตัวเองลอยอยู่ในอากาศ ม้วนตัวอยู่ในแสงสลัวของหน้าจอมอนิเตอร์ นิ้วมือของผมสั่นเทาขณะที่ยืนขึ้น ร่างกายเกร็งขึ้นตามสัญชาตญาณ ผมยืนขึ้นและกวาดสายตามองไปรอบๆ สำนักงานว่างเปล่า—แถวคอกทำงานที่เหมือนกันทอดยาวออกไปในความเงียบงัน ฉากกั้นของพวกมันกลมกลืนไปกับพื้นที่ที่มีแสงสลัว พรมสีเทานุ่มช่วยซับเสียงฝีเท้าขณะที่ผมเดินตรงไปยังห้องน้ำ ผมหยุดอยู่ที่อ่างล้างหน้า มือจับเซรามิกที่เย็นเฉียบไว้แน่น ผมเงยหน้ามองเงาสะท้อนของตัวเอง แม้ว่าแว่นตาจะช่วยพรางรอยคล้ำใต้ตาได้ แต่มันก็ไม่สามารถปิดบังได้ทั้งหมด ผมเสยผมขึ้นไปข้างหลัง แม้ทัศนวิสัยจะเป็นสีน้ำเงิน แต่ผมของผมยังคงเป็นสีดำสนิท และดวงตาที่ปกติเป็นสีน้ำตาลกลับมีสีเทาจางๆ เจืออยู่ ผมจ้องมองเงาสะท้อนอีกครู่หนึ่งก่อนจะถอดแว่นตาออก “ไม่ใส่ดูดีกว่าแฮะ” พวกมันทำให้ผมดู...

เนิร์ดเกินไปหน่อย โชคดีที่สิ่งที่มันทำมีแค่การทำให้โลกกลายเป็นสีน้ำเงิน ผมยังไม่เห็นอะไรน่าขนลุก...

ในตอนนี้ “เฮ้อ” ผมพ่นลมหายใจออกมาอีกครั้ง รู้สึกโล่งอกที่ไม่มีไอหมอกหลุดออกมาจากปากแล้ว จากนั้นผมก็วักน้ำเย็นล้างหน้า แล้วหันหลังเดินกลับไปที่โต๊ะทำงาน “หืม?” ผมเพิ่งมาถึงหน้าจอมอนิเตอร์ก็ต้องหยุดชะงัก ผมหยุดกะทันหัน สายตาจ้องเขม็งไปที่ป๊อปอัปที่ไม่คาดคิดบนหน้าจอ ความรู้สึกเดจาวูถาโถมเข้ามา “ไม่เอาอีกแล้วนะ...” แม้จะลังเล แต่ผมก็ยังเอื้อมมือไปจับเมาส์และคลิกที่แท็บนั้น ทันใดนั้น ป๊อปอัปก็หายไป และแอปพลิเคชันหนึ่งก็เริ่มดาวน์โหลดลงในมอนิเตอร์ของผม ภายในไม่กี่วินาที มันก็ติดตั้งลงบนหน้าจอโฮม—ไอคอนรูปเกมบอยที่มีอีโมจิอยู่ตรงกลาง โดยที่ดวงตาถูกแทนที่ด้วยตัว X หนาๆ สองตัว ก่อนที่ผมจะได้ตอบโต้ แอปก็เปิดขึ้นโดยอัตโนมัติ ───── ผู้พัฒนาเกม : เซธ ธอร์น สถานะ : ลำดับที่หนึ่ง ▪ โหนดพื้นฐาน : ภาชนะกักกัน ไอเทม : ▪ หน้ากากว่างเปล่า ▪ แว่นตาภูตผี ร้านค้า : ล็อกอยู่ เควสต์ : ปลดล็อกแล้ว (พร้อมใช้งาน : 1) ▪ พัฒนาเกมที่มีคะแนน 1 ดาว - รางวัล: ปลดล็อกร้านค้า เกมที่พัฒนาแล้ว : [เสียงกระซิบอันอ่อนโยน] คะแนน : ⯪☆☆☆☆(0.5) ───── ผมจ้องมองหน้าจออยู่ครู่หนึ่งก่อนจะกลืนน้ำลายอึกใหญ่ ความสนใจของผมพุ่งไปที่ส่วนของเควสต์ทันที “รางวัล...

ปลดล็อกร้านค้าเหรอ?” สำหรับรางวัลแล้ว มันดูเหมือนไม่มีอะไรมาก แต่เมื่อพิจารณาว่าเป้าหมายปัจจุบันของผมคือการหาวิธีรักษาอาการของตัวเอง ผมก็เข้าใจว่ากุญแจสำคัญในการหาทางรักษาคงอยู่ในร้านค้านั่นแหละ ในกรณีนี้ เป้าหมายแรกของผมก็ชัดเจนแล้ว “...ฉันต้องพัฒนาเกมหนึ่งดาวให้ได้” ผมชะงักไปครู่หนึ่งแล้วครางออกมา “ฉิบหายแน่ๆ” ต้องใช้ทีมงานทั้งทีมและงบประมาณมหาศาลเพื่อสร้าง *เสียงกระซิบอันอ่อนโยน* แต่มันก็ยังได้คะแนนแค่ 0.5 ดาว นั่นคือเกมที่มีงบประมาณและการผลิตขนาดพอเหมาะเลยนะ การสร้างเกมหนึ่งดาวจะเป็นความท้าทายที่หนักหนาสาหัสมาก นอกจากนั้น ความสนใจของผมก็ตกลงไปที่ส่วน 'สถานะ' “ลำดับที่หนึ่ง?

โหนดพื้นฐาน?” มีคำศัพท์หลายคำที่ผมค่อนข้างสับสน ผมรู้ว่าโหนดพื้นฐานคือสิ่งที่ผมปลดล็อกผ่านรางวัล แต่จนถึงตอนนี้ ผมก็ยังไม่รู้วิธีใช้งานมัน *'ฉันควรถามระบบประหลาดนี่ดีไหม?'* มันจะตอบหรือเปล่า?

มันเงียบกริบอย่างน่าขนลุกมาหลายนาทีแล้ว ก่อนที่ผมจะได้พูดอะไร ผมก็ได้ยินเสียงคลิกเบาๆ จากข้างหลัง *คลิก!* ด้วยความตกใจ ผมหันไปเห็นร่างที่ดูซูบเซียวเดินโซเซเข้ามา เสื้อเชิ้ตสีขาวของเขาหลุดลุ่ย และเนกไทก็แขวนอยู่อย่างหลวมๆ รอบคอ ผมสีน้ำตาลของเขายุ่งเหยิง เป็นสัญญาณชัดเจนของการอดนอน และกลิ่นเหล้าฉุนกึกก็ติดตัวเขามาด้วย “อ้าว เซธ” เขาคือเอลเบิร์ต หนึ่งในเพื่อนร่วมงานในโปรเจกต์ของผม “อรุณสวัสดิ์...?” ผมเช็กเวลา และต้องตกใจที่เห็นว่าเกือบ 6 โมงเช้าแล้ว 'เวลาผ่านไปเร็วขนาดนี้ได้ยังไง?' ผมก้มมองเสื้อผ้าที่ยับยู่ยี่ของตัวเอง ไม่มีทางที่ผมจะเผชิญหน้ากับหัวหน้าแผนกในสภาพแบบนี้ได้ โดยไม่ทันคิด ผมมุ่งหน้าตรงไปยังห้องน้ำ หากผมยังมีโอกาสแม้เพียงน้อยนิดที่จะไม่ถูกไล่ออก ผมต้องดูดีขึ้นมาบ้าง ไม่อย่างนั้น โอกาสที่ผมจะพัฒนาเกมหนึ่งดาวก็แทบจะเป็นศูนย์ ผมจะสร้างเกมด้วยตัวคนเดียวได้ยังไง?

*'ใช่ ฉันแค่ต้องแสดงให้เห็นว่าฉันยังทุ่มเทให้กับทีม ฉันแค่—'* “นายจะไปไหนน่ะ?” แต่ทันทีที่ผมเริ่มขยับ เสียงของเอลเบิร์ตก็หยุดผมไว้ ผมชะงักแล้วมองไปที่เขา “ฉันจะไปเปลี่ยนชุดน่ะ ฉันโต้รุ่งมาทั้งคืน เสื้อผ้าเละเทะไปหมด ฉันควรเปลี่ยนชุดก่อนที่หัวหน้าแผนกจะมา” ผมเริ่มเดินไปทางห้องน้ำ แต่เอลเบิร์ตกลับมองผมด้วยสายตาแปลกๆ “....นายไม่ได้รับข้อความเหรอ?” “ข้อความ?” ใจผมหล่นวูบเมื่อเห็นสีหน้าของเขา ได้โปรดอย่าบอกนะว่า... “พวกเราถูกเลิกจ้างแล้ว” เอลเบิร์ตหยิบโทรศัพท์ออกมา พลิกหน้าจอให้ดูข้อความล่าสุด “ทุกคนเลย”
