# ตอนที่ 16 - ทางออก

*ฟลิก!*

แสงไฟทิ่มแทงดวงตาของผม

“แฮ่ก! แฮ่ก—!”

ผมกุมหน้าอกตัวเองพลางก้มตัวลงและใช้เข่าพยุงร่างไว้ แทบจะรวมสมาธิไม่ได้เลย ปอดของผมแสบร้อนทุกครั้งที่หายใจ และขาทั้งสองข้างก็สั่นเทา เหงื่อไหลหยดจากคางไม่ขาดสาย

“บ้าเอ๊ย... ฉันอาจจะ... แฮ่ก... อ้วกแตกแน่!”

ผมรีบตะปบมือปิดปากเมื่อกระเพาะปั่นป่วนอย่างรุนแรงจนน้ำดีที่ตีตื้นขึ้นมาเกือบจะพุ่งออกมา ผมฝืนกลั้นมันไว้แล้วเงยหน้าขึ้น ประตูหกบาน ฝั่งละสามบาน ทุกบานถูกล็อค ผมกวาดสายตามองรอบข้างก่อนจะฝืนตัวเดินไปข้างหน้าอีกครั้ง

“.....!”

ขณะที่ขยับ ขาของผมทำท่าจะทรุดลงด้วยความเหนื่อยล้า และทุกลมหายใจก็เผาไหม้ราวกับกองไฟในปอด

*'ฉันควรจะ... เลิกเลยดีไหม?'*

ผมทนต่อไปได้อีกไม่นานแล้ว ความจริงคือผมอยู่บนขอบเหวของการล้มพับ ถ้าผมฝืนตัวเองต่อไป เสียงฝีเท้านั่นจะตามมาทัน ไม่ว่าจะเป็นรอบนี้หรือรอบหน้า... ถ้ามันเกิดขึ้นล่ะก็— ความหนาวเหนือกะทันหันแล่นพล่านไปทั่วร่าง

*'ฉันควรจะเลิกซะ ฉันหาทุกอย่างที่จำเป็นต้องหาเจอหมดแล้ว'*

เป้าหมายหลักคือการมาสัมผัสว่าสคริปต์ระดับต่ำมันทำงานยังไง ซึ่งผมก็บรรลุเป้าหมายแล้ว ในแง่นั้น ผมสามารถเลิกตอนนี้แล้วกลับไปสร้างเกมต่อได้เลย ขณะที่ริมฝีปากของผมเผยอออกและคำว่า 'ฉันขอเลิก' กำลังจะหลุดออกมา ผมก็ชะงักไป

“....”

ผมจ้องมองไปข้างหน้าพลางเลียริมฝีปาก

*'ไหนๆ ก็ไหนๆ แล้ว ลองดูหน่อยจะเป็นไรไป...?'*

ผมอยากเห็นว่าความเปลี่ยนแปลงอะไรจะเกิดขึ้นเมื่อผมเลี้ยวตรงหัวมุม แม้ระยะทางจะสั้น แต่มันก็ต้องใช้ความพยายามอย่างมาก และเมื่อผมทำได้ สายตาของผมก็ตกไปที่ทางเดินข้างหน้า ผนังสีขาวแบบเดิม กล้องวงจรปิดที่อยู่ไกลๆ แบบเดิม ประตูหกบานแบบเดิม ทุกอย่างข้างหน้าเหมือนเดิมเป๊ะ ทุกอย่—

“เอ๊ะ?”

เดี๋ยวก่อน ผมกะพริบตาแล้วมองไปรอบตัว ประตูหกบานงั้นเหรอ? ดวงตาของผมเบิกกว้างเมื่อตระหนักได้ แต่ก่อนที่ผมจะได้ประมวลผลสถานการณ์อย่างถี่ถ้วน แสงไฟเหนือหัวก็กะพริบ

*ฟลิก!*

อีกครั้งที่ผมถูกโยนลงสู่ความมืดมิด ทันทีที่มันเกิดขึ้น ร่างกายของผมก็เกร็งเครียด และหัวใจก็บีบรัดแน่น โดยไม่เสียเวลาแม้แต่วินาทีเดียว ผมพุ่งตัวไปข้างหน้า เสียงฝีเท้าที่เร่งรีบดังสนั่นหวั่นไหวมาจากข้างหลัง

*ตึกๆๆๆๆๆๆๆ—!*

ผมโยนความคิดทุกอย่างทิ้งไป

*'หนึ่ง...'*

ปอดของผมพ่นไฟ ขาสั่นพั่บๆ ขณะที่ผมเร่งความเร็วให้มากที่สุดเท่าที่จะทำได้ ผมแทบหายใจไม่ออก แต่ละอึกที่สูดเข้าไปรู้สึกเหมือนจะเป็นครั้งสุดท้าย เมื่ออากาศรอบตัวดูเหมือนจะเย็นลงเรื่อยๆ เสียงฝีเท้าข้างหลังขยับเข้ามาใกล้ขึ้นทุกวินาที

*'...สาม'*

พวกมันตามมาทันอย่างรวดเร็ว! ผมเหนื่อยเกินไปแล้ว ผมแทบจะรักษาความเร็วไว้ไม่ได้ และช้าลงในทุกวินาที

*ตึกๆๆๆๆๆๆๆ—!*

*'ห้า'*

ร่างกายของผมกำลังจะแตกเป็นเสี่ยงๆ ลำคอแสบร้อน เสียงนั่น—เสียงฝีเท้านั่น—ดังขึ้นเรื่อยๆ มันครอบงำทุกสิ่ง

*'เจ็ด...'*

ผมทนต่อไปไม่ไหวแล้ว ผมกำลังจะล้มลง เมื่อมองไปข้างหน้า สิ่งเดียวที่เห็นคือความมืดมิดที่ไร้จุดจบ ผมรู้ว่าผมอยู่ใกล้หัวมุมหนึ่งแล้ว

*'เก้า'*

ผมรู้สึกได้ถึงลมหายใจของมันที่ต้นคอ มันทำให้หลังคอของผมเสียวซ่านจนเกือบจะแข็งทื่ออยู่กับที่ หัวใจแทบจะกระดอนออกมาขณะที่ผมอ้าปาก มันอยู่ข้างหลังผม กำลังจะแตะตัวผมแล้ว ไม่—!

“ฉั—”

*ฟลิก!*

แสงสว่าง ผมล้มพับลงหน้าผนังสีขาว

“แฮ่ก.... แฮ่ก...”

ผมสูดอากาศเข้าปอดอย่างหนักหน่วง หัวสมองหมุนติ้ว และแทบจะรวมสมาธิไม่ได้ อย่างไรก็ตาม เมื่อค่อยๆ หันศีรษะไป ผมก็เห็นมัน ประตูหกบานแบบเดิม ผมครางออกมา รู้สึกเหมือนร่างกายทั้งร่างแทบจะพังทลาย

*'สาม...'*

ผมพยุงตัวไปยังประตูที่ใกล้ที่สุด

*คลิก*

มันล็อคอยู่

*'ห้า'*

ประตูถัดไป

*คลิก*

มันก็ล็อคเหมือนกัน

*'หก'*

*คลิก*

ล็อค

*'...เจ็ด'*

*คลิก*

ล็อค เมื่อมาถึงประตูบานที่ห้า ผมรู้สึกได้ว่าความวิตกกังวลพุ่งปรี๊ดและค่อยๆ เข้าครอบงำจิตใจ เวลาเดินไปเรื่อยๆ และประตูทุกบานยังคงล็อคอยู่ มือของผมสั่นเทาขณะเอื้อมไปหาประตูบานที่ห้า

*'ได้โปรดเถอะ ขอร้องล่ะ...!'*

ผมสัมผัสที่มือจับ

*'แปด'*

*คลิก!*

“.....!?”

เสียงคลิกที่คุ้นเคยดังสะท้อนขึ้น แต่ก่อนที่หัวใจของผมจะหล่นวูบ ผมก็เห็นประตูค่อยๆ เปิดออก ดวงตาของผมเบิกกว้าง มันได้ผล! แต่ทันทีที่ผมเปิดประตูได้ แสงไฟข้างหลังผมก็กะพริบ

*ฟลิก!*

ความมืด

“.....!?”

ผมไม่คิดซ้ำสอง ทันทีที่ความมืดมาเยือน ผมรีบพุ่งตัวเข้าไปในห้องและกระแทกประตูปิดตามหลังทันที พร้อมกับล็อคมันโดยตรง

*ปัง!*

“แฮ่ก... แฮ่ก!”

ผมทรุดตัวลงกับพื้น รู้สึกว่าเข่ามันหมดแรงไปดื้อๆ ขณะที่สูดหายใจเข้าปอดอีกครั้ง มือสัมผัสพื้นขณะที่หัวเริ่มหมุน ผมไม่ไหวแล้ว แทบจะยกนิ้วไม่ขึ้น นี่คือจุดที่ความอึดของผมสิ้นสุดลง ผมไม่รู้ว่าเวลาผ่านไปนานแค่ไหนตั้งแต่เข้ามาในห้อง แต่ทันทีที่ผมกู้ลมหายใจกลับมาและเงยหน้าขึ้นได้ ผมก็มองไปรอบๆ

“อะไรกันเนี่ย...”

ตอนนั้นเองที่ผมสังเกตเห็น ผมอยู่ในห้องเล็กๆ ที่ไม่มีหน้าต่าง มีโต๊ะไม้ตัวเดียวตั้งอยู่ตรงกลาง พร้อมกับเก้าอี้ธรรมดาๆ และคอมพิวเตอร์เก่าๆ เครื่องหนึ่ง หน้าจอเปิดอยู่แล้ว ส่งแสงสลัวๆ กะพริบๆ ที่พอจะให้ความสว่างแก่พื้นที่รอบๆ ได้บ้าง แสงริบหรี่นั่นเป็นสิ่งเดียวที่กันความมืดเอาไว้ ไม่มีอะไรอย่างอื่นเลย—ไม่มีของตกแต่ง ไม่มีเสียง มีเพียงความเงียบที่น่าขนลุกและเสียงหึ่งๆ ของเครื่องจักร อากาศรู้สึกหนักอึ้งขึ้น อับชื้น เหมือนมีใครบางคนเพิ่งจะพ่นลมหายใจออกมาในพื้นที่นี้เมื่อไม่กี่วินาทีก่อน ผมค่อยๆ ดันตัวขึ้นและนั่งลงบนเก้าอี้ก่อนจะมองไปที่คอมพิวเตอร์

“กล้องวงจรปิด...”

หน้าจอแสดงภาพทางเดิน *ทางเดินนั้น* ประตูทั้งหกบานอยู่ในสายตา

*'มันคือทางเดินเดียวกับที่ฉันเพิ่งอยู่มานี่นา ฉันเห็นประตูทั้งหกบานเลยด้วย'*

ขณะที่ผมกำลังสังเกตวิดีโออยู่ จู่ๆ หน้าจอก็กลายเป็นสีดำ และผมก็สะดุ้ง อย่างไรก็ตาม ในไม่ช้าผมก็สงบลงเมื่อเห็นข้อความสีเขียวข้างล่าง

**[คุณต้องการเปิดโหมดมองเห็นในเวลากลางคืน (Night-vision) หรือไม่?]**

*'มีฟีเจอร์นี้ด้วยเหรอ?'*

ผมเอื้อมมือไปที่เมาส์แพดและกำลังจะกดยืนยันตอนที่ผมสังเกตเห็นบางอย่าง

*'มีไทม์สแตมป์อยู่ที่ด้านล่าง และมันยาวเท่ากับเวลาที่ฉันอยู่ที่นี่เลย'*

ประมาณสองสามนาที ความคิดหนึ่งแวบเข้ามา ผมจึงเอื้อมมือไปที่แถบเวลาแล้วเลื่อนเวลากลับไป วิดีโอเริ่มเปลี่ยนไป และดวงตาของผมก็เบิกกว้างหลังจากนั้นไม่นาน เมื่อเห็นร่างของตัวเองปรากฏบนหน้าจอ กำลังหอบหายใจขณะที่เอื้อมมือไปหาประตูอย่างสิ้นหวัง ทางเดินยังคงสว่างไสว

*'ฉันดูสภาพแย่ชะมัด'*

ตั้งแต่ผมเผ้าไปจนถึงเสื้อผ้า ทุกอย่างดูไม่ได้เลย ภาพนั้นทำให้ผมตื่นเต็มตาขณะที่หน้าจอคอมพิวเตอร์กลายเป็นสีดำหลังจากนั้นไม่นาน

*'อา นี่ต้องเป็นตอนที่ไฟดับแน่ๆ'*

ผมกำลังจะข้ามส่วนนี้ไปตอนที่เห็นข้อความเดิมปรากฏขึ้น

**[คุณต้องการเปิดโหมดมองเห็นในเวลากลางคืน (Night-vision) หรือไม่?]**

“เดี๋ยวนะ นี่มันใช้กับวิดีโอที่บันทึกไว้ได้ด้วยเหรอ?”

ผมกลั้นหายใจก่อนจะคลิก 'ตกลง' ทันใดนั้น ภาพที่บันทึกไว้ก็กลายเป็นสีเขียว และวินาทีที่มันเปลี่ยนไป ลมหายใจของผมแทบจะหลุดออกจากร่าง เมื่อผมเห็นร่างหนึ่งยืนอยู่ข้างหลังตัวผมในวิดีโอ มือสีดำเรียวยาวของมันเอื้อมมาหาผมขณะที่ผมวิ่งไปข้างหน้าอย่างบ้าคลั่ง

*'ดูจากจังหวะและความลนลานที่ฉันวิ่ง ดูเหมือนจะเป็นรอบนี้นี่แหละ'*

ผมกุมคางพลางจ้องมองร่างนั้น และในตอนที่เวลาสิบวินาทีกำลังจะหมดลงนั่นเองที่ผมสังเกตเห็นความผิดปกติบางอย่าง

“หือ?”

แทนที่จะหายไปเฉยๆ ก่อนที่ตัวจับเวลาจะรีเซ็ตใหม่ทั้งหมด เงาร่างนั้นขยับไปที่ประตูบานหนึ่งแล้วเข้าไปข้างใน แสงไฟสว่างขึ้นหลังจากนั้นไม่นาน ผมปรากฏตัวขึ้นหลังจากนั้น เลี้ยวตรงหัวมุมขณะที่กล้องแสดงภาพผมเคลื่อนที่จากปลายทางเดินด้านหนึ่งไปยังอีกด้านหนึ่ง

*'เห็นแบบนี้แล้วรู้สึกแปลกพิลึกแฮะ'*

มันทำงานแบบเดียวกันหรือเปล่าตอนที่ยังไม่มีประตูในสองสามรอบแรก? อย่างไรก็ตาม ในที่สุดวิดีโอก็ตามมาถึงช่วงเวลาสุดท้ายของผมในทางเดิน บานแรก บานที่สอง บานที่สาม บานที่สี่ ผมเฝ้าดูตัวเองในวิดีโอพยายามจะเข้าห้องแต่ละห้อง บานที่ห้—

*'เดี๋ยวก่อน...'*

ความคิดของผมหยุดชะงักเมื่อเห็นตัวเองเอื้อมมือไปที่ประตูบานที่ห้า ความจริงที่น่าสะพรึงกลัวถาโถมเข้ามาหลังจากนั้นไม่นาน เมื่อประตูเปิดออกและผมก็เข้าไปข้างใน นั่นมัน...

*'นั่นมันประตูเดียวกับที่เงาร่างนั้นเข้าไปนี่!'*

“ฮ่า...”

เสียงถอนหายใจ อุ่น... ชื้น... มันทำให้หลังคอของผมเสียวซ่านขณะที่ร่างกายทั้งร่างเย็นเฉียบ ความจริงปรากฏชัดแจ้งในทันที ผม... ไม่ได้อยู่ในห้องนี้คนเดียว
