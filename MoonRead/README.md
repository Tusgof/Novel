# MoonRead

Stardust-themed private web reader for verified Thai Markdown chapters generated by the Novel workspace.

Brand palette:

- Navy: `#121926`
- Gold: `#EBC05F`
- Logo text/cream: `#F0F0F0`

## Local Workflow

Run from this directory:

```powershell
npm.cmd install
npm.cmd run generate:chapters
npm.cmd run dev
```

The importer reads translated chapters from:

```text
D:\Fogust\Workspace\Novel\Deep Sea Embers\05_Output\chXXX\chXXX.md
D:\Fogust\Workspace\Novel\Horror Game Developers\05_Output\chXXX\chXXX.md
```

It writes read-only reader artifacts to:

```text
content/generated/
```

The reader supports configured chapter ranges per book. Missing chapters are shown as unavailable until the source Markdown exists and passes validation.

Current generated reader content: Deep Sea Embers `ch001-ch080` and Horror Game Developer `ch001-ch080`.

## Validation

`npm.cmd run generate:chapters` rejects chapters with:

- missing H1 title
- empty or too-short content
- bad encoding markers
- unintended Chinese body text
- provider/meta leakage

Rejected chapters are not linked in the reader UI. See `content/generated/import-report.md` after generation.

## Vercel

Use the existing GitHub-Vercel connection and import this repository with:

- Root Directory: `MoonRead`
- Framework Preset: `Next.js`
- Install Command: `npm install`
- Build Command: `npm run build`

No API keys or provider credentials are required for the reader web.

If the repository is a monorepo, make sure Vercel points to `MoonRead`, not a novel folder.

Vercel does not need access to novel `05_Output` folders. Commit `content/generated/` after running `npm.cmd run generate:chapters` locally, then Vercel builds from that generated reader content.

## GitHub

Commit the `MoonRead/` directory plus generated reader content when you want Vercel to deploy the latest readable chapters.

Do not commit:

- Vercel tokens
- provider API keys
- `.vercel/`
- `node_modules/`
- `.next/`

## Updating Chapters

After another translation run updates `05_Output`, regenerate and rebuild:

```powershell
npm.cmd run generate:chapters
npm.cmd run build
```

Then commit the changed `MoonRead/content/generated/` files and push to GitHub. Vercel will deploy from GitHub after the push.

## Verification

```powershell
npm.cmd run lint
npm.cmd audit --omit=dev
npm.cmd run build
npm.cmd run smoke
```

`npm.cmd run smoke` starts a temporary local Next.js server, verifies desktop and mobile reader flows with Playwright, then writes screenshots and a JSON result under `output/playwright/`.
