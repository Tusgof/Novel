## Design Direction

Reference principles used:

- strong genre signal at thumbnail size
- one clear focal image
- restrained palette
- high contrast silhouette
- uncluttered upper area for title typography
- no baked-in text, logo, watermark, author name, or title

Useful references:

- Reedsy: genre signaling matters for cover design: https://reedsy.com/blog/guide/book-cover-design/how-to-design/
- AuthorHouse: use contrast, negative space, and a strong visual concept: https://www.authorhouse.com/en/resources/publishing/book-cover-design-101-creating-an-eye-catching-book-cover
- Inkers Con: keep covers focused on key genre/tone elements and avoid clutter: https://inkerscon.com/book-cover-design-dos-and-donts/

## Deep Sea Embers Prompt Summary

Dark nautical fantasy cover. A lone captain faces a ghostly tall sailing ship emerging from moonlit fog over a supernatural ocean, with ruined lighthouse silhouettes and small ember accents. Painterly realism, muted teal/charcoal palette, upper negative space for title.

## Horror Game Developer Prompt Summary

Horror-system cover. A young exhausted game developer stands in a decayed opera theater holding a blank clown mask, with eyeless orchestra silhouettes and faint game UI panels behind him. Painterly cinematic horror style, black/burgundy/old-gold palette, upper negative space for title.
